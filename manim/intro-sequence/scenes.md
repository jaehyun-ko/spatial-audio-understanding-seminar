# 도입부 2–7: 공간 관측의 연속 장면

## 범위와 구성
기존 덱의 2–7번만 대체한다. 1번과 8–78번은 유지한다. 음원은 특정 알람이 아닌 일반 음원 s(t). 1136×404 본문 프레임, 라이트 배경, 기존 Pretendard와 색상 체계를 따른다. 하나의 Manim Scene을 여섯 구간으로 렌더링하며 구간 경계에서 화면 상태를 그대로 넘긴다. 각 구간 끝은 발표용 정지 지점이다.

## 공통 과학 모델
- 오른손 좌표계 O. M1=(-d/2,0,0), M2=(d/2,0,0).
- 방위각 α: +x에서 +y 방향. 고도각 β: xy 평면에서 +z 방향. 거리 r=||p_s||.
- p_s=r(cosβ cosα, cosβ sinα, sinβ).
- 직접 경로 길이 ℓ_m=||p_s-p_m||, t_m=ℓ_m/c, τ=t2−t1=(ℓ2−ℓ1)/c, c=343 m/s.
- 파형은 설명용 가우시안 창 펄스의 지연·감쇠를 계산한다. 실험 결과가 아니다.
- 잔향 장면은 y=3.8 m 벽의 1차 정반사 경로를 이미지 음원으로 계산한다. 전체 잔향장을 시뮬레이션했다고 주장하지 않는다. 두 번째 음원은 별도 펄스이며 선형으로 합산한다.
- 두 마이크의 단일 시간차가 방위각·고도각·거리 전체를 유일하게 결정하지 않는다.
- 3차원 점·호·직선은 동일한 명시적 oblique projection으로 2차원 프레임에 표시한다. 화면상의 선 길이가 물리 거리라고 해석하지 않는다. 수치는 모두 투영 전 3차원 좌표에서 계산한다.

## 2. 공간 오디오 이해의 목표
목적: 입력보다 먼저 알아내려는 음원과 공간 좌표 정의.
음원·마이크·좌표축 생성. 원점과 수평 투영을 유지하며 α, β, r를 순서대로 그린다. 오른쪽에 방위각·고도각·거리 대응을 조판한다. 약 10초.

## 3. 두 채널 관측 신호
목적: 공간상의 소리가 각 마이크의 시간 신호가 되는 과정.
같은 음원과 마이크 유지. 좌표 정의 라벨을 정리하고 두 전파 경로를 만든다. 공통 전파 시간으로 두 경로 위 펄스와 두 관측 파형을 동시에 전개한다. 약 10초.

## 4. 경로 차이와 시간차
목적: 기하와 관측의 인과 관계.
동일한 r·β에서 방위각을 이동. ℓ1, ℓ2, t1, t2와 두 파형을 동시에 갱신한다. τ의 부호가 바뀌는 과정과 τ=(ℓ2−ℓ1)/c를 함께 표시한다. 모호성 경계는 노트에 보존. 약 12초.

## 5. 잔향과 음원 혼합
목적: 관측에 반사 경로와 다른 음원까지 더해지는 과정.
같은 장면에 벽, 1차 반사 경로, 해당 지연 펄스를 추가. 다음으로 두 번째 음원과 관측 기여를 추가한다. 식 x_m=∑_k h_mk*s_k+v_m를 실제 도형의 대응 색으로 조판한다. 약 13초.

## 6. 마이크 배열 기하
목적: 음원 위치가 같아도 마이크 배치에 따라 관측이 달라짐.
직접음만 비교하는 상태로 천천히 돌아온다. 음원과 기준 좌표 고정. 마이크 간격 d만 바꾸며 시간차를 정확한 거리 식으로 갱신한다. 원거리 근사와 유한거리 값을 혼용하지 않는다. 약 10초.

## 7. 공간 표현·언어 결합·평가
목적: 같은 관측과 장면을 논문의 세 연구 관점에 연결.
기하와 파형 일부를 남겨 좌표 출력, 음원별 의미·위치 연결, 관측과 판단의 비교를 차례로 드러낸다. 세 관점은 단일 모델의 고정 구조가 아니라 발표 범위다. 다음 8번의 방향 탐색으로 연결한다. 약 10초.
