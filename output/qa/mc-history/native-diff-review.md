# Native PPTX residual-difference review

최종 MC Audio-LM 연구사 PPTX의 보존 슬라이드 중 `render-diff.json`에서 `inspect difference`로 분류된 **28개**를 독립적으로 검수했다. 모든 차이를 이전·현재 렌더의 같은 위치 crop으로 나란히 확인했다. **텍스트 변경, 잘림, 의미 손실, 추가 줄바꿈은 발견하지 않았다. 수정 필요 사항은 없다.**

## Scope and method

- 이전 렌더: `tmp/localization-pptx-qa/slide-NN.png` (80장 버전).
- 현재 렌더: `tmp/mc-history-pptx-qa/slide-NN.png` (85장 최종 버전).
- 대응은 기존 안정 ID와 `output/qa/mc-history/render-diff.json`의 old/new mapping을 사용했다. 새 제목·챕터·페이지 번호는 이번 잔여 차이 검수 대상이 아니다.
- 원래 비교 구역은 전체 너비와 y145–681이다. diff의 y좌표는 이 구역에 대한 상대값이므로 검수 crop에서 **145px를 더해** 실제 화면 위치로 변환했다.
- 28개 전후 crop을 7개 비교 시트로 만들어 모두 직접 읽었다. 원본 크기를 유지한 개별 pair와 시트는 `tmp/mc-history-native-diff-crops/`에 보존했다.
- 두 candidate의 geometry 기록에서 y145 이상, y680 미만의 본문·핵심 문장·출처 텍스트를 비교했다. 슬라이드 순서에 따라 달라지는 shapeName만 제외하고 **문자열, 위치, 폭·높이, 링크 및 서식이 28개 모두 정확히 일치**했다.
- 별도 JSON 검증 기록: `output/qa/mc-history/native-diff-geometry.json`.

## Finding

잔여 차이는 글자의 윤곽과 국소적인 자간 렌더에 국한되며, 보존된 문구의 글자 순서와 완결성은 유지된다. 슬라이드별 차이 픽셀은 58–2,582개다. 이는 동일한 텍스트·geometry·서식을 LibreOffice로 렌더할 때 발생하는 국소적인 글꼴 래스터 차이와 일치하는 양상이다. 정확한 캐시 또는 렌더러 내부 원인은 추정하지 않는다.

S79의 본문 질문도 별도로 대조했다. 나머지는 하단 핵심 문장이나 작은 출처의 차이이며, 각 문장의 시작·끝, 강조 범위 및 기호가 모두 보존되어 있다. 검토 대상의 라이트 배경과 글자 대비도 유지된다. 기존 비교 기록에서 보존 PDF 본문 75개가 픽셀 단위로 동일하다는 결과와도 충돌하지 않는다.

## Limits

이 기록은 자동 비교가 표시한 28개 잔여 차이의 검수 결과다. 새로 추가하거나 의도적으로 변경한 페이지의 별도 검수 기록을 대체하지 않으며, 85개 전체 페이지를 이번 단계에서 다시 보았다고 주장하지 않는다. Microsoft PowerPoint 앱 자체의 렌더 검증은 수행하지 않았다.

추가 최종 검수: native PPTX S16·S22·S24·S28·S37을 각각 전체 화면으로 확인했으며, 도식·제목·핵심 문장·출처의 배치와 라이트 테마가 유지되고 잘림·겹침·문구 손실이 없어 모두 통과했다. S22 핵심 문장 끝부분은 실제 PNG crop으로 완결성을 재확인했다.
