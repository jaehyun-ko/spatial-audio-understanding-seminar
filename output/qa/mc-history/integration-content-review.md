# MC Audio-LM 연구사 독립 검수

검수일: 2026-09-11. 최종 85장(본문 49장·근거 부록 36장), 핵심 논문 27편 기준이다.

- PDF 렌더 S15–41와 S48을 한 장씩 확인했다. 라이트 테마, 제목 위계, 수식, 그래프 수치와 연구사 도식이 읽히며 S48 네이티브 HTML 종합표도 확인했다. S35의 최종 문구 “별도 exact-MCQA”를 재렌더에서 확인했다.
- BAT 최초 공개와 채택 수정판, 2025년 DSpAST·Motion·OWL의 동시기 분화, 기존 Audio-LM의 공간 확장, 2026년 시간 표현 확장 순서를 원문 근거와 대조했다. Motion의 JSON 텍스트 입력과 OWL의 연속 오디오 토큰 입력, 입력 인터페이스와 LoRA 학습의 차이를 확인했다.
- E/P/LM의 학습 단계를 분리하고, 저자가 명시한 계승과 병렬 연구를 구별했다. TWNM Table 15의 semantic-judge 3개 값과 Table 5 exact MCQA, ST-AudioLM의 동일 41-token 조건과 시간 표현 학습을 혼동하지 않는지 확인했다.
- 모든 85장에 발표 노트가 있으며 부록 구분장 S50을 제외한 84장에 URL 출처가 있다. 재배열로 잘못된 전환이 남았던 8개 슬라이드를 제보했고 최종 소스에서 수정 반영을 확인했다.
- 기존 23개 차트의 99개 보고값과 별도 TWNM 어댑터 값 39.20/46.40/52.10이 유지됐다. 모든 현재 차트 파일·참조·발표 노트·생성 데이터·표시 수치를 대조했다. S85의 세 0값은 0크기 구간을 생략하는 원래 막대 표현이고 데이터·노트와 실제 SVG 기하에 보존돼 있다.
- 새 연구사 설명 7장은 도식 6장과 네이티브 HTML 표 1장이다. 담당 지속문서 4개에서 85장 순서, S15 제목, 이 구성과 99+3 수치 범위를 맞췄다.

수정이 필요한 추가 내용 또는 진행을 막는 시각 문제는 발견하지 않았다. 원문 이미지의 고유 색과 래스터 해상도는 유지된다. 이 기록의 개별 렌더 검수 범위는 S15–41와 S48이며 전체 PPT 패키지·기하 검수는 별도 기록을 따른다. 기준 이전 파일의 바이트 해시가 없어 이전과 바이트 단위 동일하다고 주장하지 않는다.
