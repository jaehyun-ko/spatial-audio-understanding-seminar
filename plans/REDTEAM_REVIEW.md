# 전체 흐름 레드팀 검토와 설계 결정

검토일: 2026-09-09 · 대상: [레드팀 이전 78장안](narrative-78-slide-pre-redteam.md)

## 판정

27편의 범위는 이번 청각 판단 중심 세미나에 충분한 작업 범위다. **부족한 것은 논문 수보다 질문 사이의 구별, 결과의 비교 조건, 평가가 허용하는 결론의 경계였다.** 이 문서의 ‘수정’은 설계 수정이지 원문 오류 해결, 모델 재현, 이미지 확보 또는 실제 슬라이드의 검증 완료를 뜻하지 않는다.

핵심 반론은 “SELD도 이미 사건과 위치를 붙이는데 왜 다시 binding인가?”, “다른 입력·학습 조건의 모델을 발전 순서로 읽어도 되는가?”, “끝의 진단 연구가 앞 모델 모두의 실패를 증명하는가?”였다. 세 질문에 답하도록 전체 전환을 바꿨다.

## 2. 논문 역할·근거 측면에서 바로잡은 내용

원문 링크와 표·행·조건은 각 [근거 카드](EVIDENCE_LEDGER.md)에 있다. 아래는 설계를 실제로 바꾼 쟁점이다.

| 대상 | 원래 생길 수 있는 잘못된 주장 | 설계의 처리 |
| --- | --- | --- |
| Neural-SRP | 실녹음 zero-shot 전이, 표보다 큰 개선율 | Table I의 SRP/NeuralSRP+ 원수치 사용. ‘+’의 250개 실녹음 적응 표시 |
| AGG-RL | Dynamic은 움직이는 음원, 모든 배열에서 모듈만 넣으면 향상 | Dynamic-S/U는 배열 조건. 같은 모델의 AGG 결합과 전체 Proposed 비교 분리; S 조건 비개선도 유지 |
| MC-SimCLR | DOA만 시험, 전체 augmentation이 항상 최선 | LP의 사건+방향 두 지표를 주비교. FT·augmentation은 별도 부록 |
| CCSR | 미관측 채널 전체 생성, frozen 표현이 supervised보다 우월 | 가린 STFT 프레임 복원. 실제 두 분기 masking과 목표 개념도 구별. TDOA 이득과 C50 반례 유지 |
| LAM | 라벨/기하 정보 없이 범용 표현 학습, LE만 낮으면 승리 | 알려진 steering matrix, CSM 복원, 판독 종류를 명시. 주근거는 같은 모델의 threshold별 LE/LR |
| SFD | 교사 네트워크 하나, 10분만으로 전체 학습 | clean 비잔향 특징별 별도 변형. 960h 소스 기반 사전학습 후 1h 라벨 FT; Fig. 2 채택 |
| AT2SELD | 의미 사전학습 결합의 보편적 우월성 | 강한 dropout의 Stage 3 내 결합 위치 비교로 한정. 저하된 기준을 회복하는 조건 설명 |
| GRAM | Table 2 전체 실녹음, direct transfer=zero-shot | 위치의 고정 표현 판독이 주근거. TAU 실측 RIR 합성과 실제 STARSS23 FT 구별 |
| ELSA | 검색/프롬프트 분류가 생성형 QA, 합성 성공이 실환경 해결 | 4방향 prompt 분류의 합성/실제 격차를 주결과. CLAP 입력 차이는 부록에서 명시 |
| SALM | 표현 분리 증명, 위치 판독도 zero-shot | 동일 모델 loss ablation의 검색/지도 DOA 결과. 임베딩 editing과 파형 생성 구별 |
| SelectTSL | TP MAE가 전체 성능, MOTA*가 identity tracking | MAE와 F1 동시 표시. Table VI 선택, Table III 내부 불일치는 보류. 실측 RIR 정적 합성과 현장 이동 녹음 구별 |
| BAT | mono/final binaural 비교가 입력 하나의 통제 | Table 4의 최종 prompt-only/binaural+prompt 주비교. mono의 stage 차이와 C/D 데이터 양 변화 명시 |
| DSpAST | BAT 원논문 점수→새 논문 점수의 직접 상승 | 같은 논문 Table 3의 single-stage interface 비교. 구조·특징·학습 변경을 단일 분기의 인과 효과로 압축하지 않음 |
| OWL | geometry가 모든 QA 향상의 원인, 모든 위치 지표 우수 | Table 5 기하 손실 비교와 Table 4 시스템 QA를 분리. SSQA MAE 반례와 4/12bin 혼용 경고 |
| Dual-BEATs | 좌우 panning 일반화=새 HRTF/배열 일반화 | amplitude-panned stereo L/C/R와 전처리 개입으로 한정 |
| PhaseCoder | 임의 배열 QA가 중첩 분리/전사도 모두 개선 | v2 비중첩 연결 QA, 좌표 입력, RSL 재구성과 WER 필터 표시. targeted WER 악화를 유지 |
| Sci-Phi | 속성별 맞춤 점수만 높으면 올바른 음원 묶음 | source-wise matching 원칙과 TupleScore. matching 규칙의 차이를 학습 ablation으로 그리지 않음 |
| Spatial-Omni | 추가 토큰만으로 모든 일반 오디오 능력 보존 | 동일 backbone의 zero-spatial 비교를 주근거. 일반 오디오 MIX는 부분 회복이며 별도 부록 |
| TWNM | SAPO가 전 과제 향상, corruption 비교가 순수 audio 효과 | L3 개선과 L1/L2 하락을 함께 표시. parser·답 형식·분할 한계 유지 |
| Motion/Dynamic QA | training-free encoder, 하위 +5.1이 전체 개선 | LLM 연결 무학습과 학습된 지각기를 구분. 같은 masking/thinking 설정의 전체 점수 사용 |
| ST-AudioLM | 평균 성공이 시간 조건 관계 전체 해결 | Table 5 평균과 어려운 movement-condition 하위 과제를 함께 읽음 |
| CoSTALA | 최종 temporal embedding/자동 경계/연속 이동 모두 평가 | §3.1 E_global↔T_st 검색, 원 segment duration 사용, 비중첩 두 사건 범위를 명시 |
| STAR-Bench | 캡션 비교가 phase-only 통제, 모든 최신 모델의 실패 | 캡션 정보 손실과 Table 2 시스템 평가를 분리. 시험 모델/버전 범위 고정 |
| WearVox | MC가 모든 raw 채널, phase가 이득의 유일 원인 | channel0+beamformed 입력과 학습 조건. side-talk 응답 판단의 시스템 비교 |
| SARL | 낮은 linear probe=인코더에 정보 없음 | mean pooling 이후 판독의 접근성. native 입력 및 생성 파이프라인 차이 표시 |
| BMLD | 임베딩 거리비=사람 역치, 반응/소실=phase 기전 확정 | 동일 noise seed, 파형·간섭 부수 변화, mono 구성상0, 유의한 cell 비율과 정확도 구분 |

## 4. 바뀐 전환 문장

- B→C: “위치를 출력하도록 학습한 시스템을 보았다. 이제 무엇을 배워 두고 어떤 판독기로 다시 읽었는지 구분하자.”
- C→D: “표현에 정보가 남는다는 결과 다음에는 그 표현을 문장과 맞추거나 요청한 대상에만 적용할 수 있는지 묻는다.”
- D→E: “검색 점수와 목표 DOA는 답의 한 형식이다. 질문별 답변을 만들려면 어떤 연결이 추가되는가?”
- E→F: “질문 하나의 정답을 넘어 음원별 속성 묶음과 여러 관계가 일관되는지 보자.”
- F→G: “같은 음원 목록과 위치라도 사건 순서, 궤적, 질문 관련 구간은 각각 달라질 수 있다.”
- G→H: “서로 다른 과제의 보고 성과를 보았다. 이제 무엇을 시험한 증거인지부터 나눠 읽자.”
- H→I: “한 개의 최종 점수는 없다. 처음의 질문에 각 연구가 답한 조건과 아직 빈 조건을 회수하자.”
