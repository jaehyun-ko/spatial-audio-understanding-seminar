# 장별 제작 명세 — S67–S78

상위 설계: [NARRATIVE_PLAN.md](../NARRATIVE_PLAN.md) · [근거 인덱스](EVIDENCE_LEDGER.md) · [S38–S66](BLUEPRINT_PART2.md)

이 절은 앞 모델들을 일괄 반박하는 결말이 아니다. 실험 대상과 측정 수준을 먼저 나눈다. ‘검증됨’에는 반드시 조건을 붙이고, 미보고와 실패를 구별한다. 아래의 후속 통제 제안은 실제 수행한 실험이 아니다.

### S67. 무엇을 바꾸고 무엇을 측정하는가?

- 청중 질문: 지금까지의 좋은 답변 점수만으로 공간 정보를 읽고 특정 청각 단서를 썼다고 말할 수 있는가?
- 남길 한 문장: 시스템의 답, 고정 표현의 판독, 자극 변경에 대한 반응은 서로 다른 증거다.
- 화면·근거: 상위 설계 H의 네 행 표를 사용한다. STAR는 Gemini 2.5 Pro QA, WearVox는 SC/MC Wearllama, SARL은 S-AST·SFD·GRAM-B/F 등의 고정 표현, BMLD는 Spatial-AST·DSpAST·GRAM-T·WavJEPA의 선택 반응이다. 열은 시험 대상 / 바꾼 조건 / 측정값이다.
- 설명 순서: S66의 검색 결과도 특정 출력 계약임을 회수한다. 그다음 ‘답을 맞혔는가 / 정보가 읽히는가 / 단서 변경에 반응하는가’를 읽는다. WearVox는 별도의 실제 응답 대상 판단 사례로 위치시킨다.
- 경계·부록: Spatial-AST 인코더와 BAT 전체 QA 시스템, SARL의 GRAM-B/F와 BMLD의 GRAM-T를 동일 평가 객체로 연결하지 않는다. 단계별 보장 사다리가 아니며 전체 시험 모델 목록은 근거 대장과 부록이다.
- 다음 연결: 먼저 답변 평가 자체가 어떤 청각 정보를 요구하도록 설계되었는지 살핀다.

### S68. 설명문으로 대체할 때 사라지는 청각 정보

- 청중 질문: ‘말소리와 알람이 있다’는 문장만 받았을 때도 방향·미세한 시간 질문에 답할 수 있는가?
- 남길 한 문장: 평가하려는 단서가 설명문에 보존되는지부터 따져야 한다.
- 화면·근거: P24 STAR-Bench Fig. 1의 audio/caption 문제 비교에서 관련 부분 하나를 주화면으로 둔다. 필요하면 Fig. 2의 공간 질문 하나를 출처가 있는 예제로 대체한다. 그림은 벤치마크 동기이지 특정 모델의 phase 사용 결과가 아니다.
- 설명 순서: 원음을 듣는 조건과 문장으로 전달받는 조건을 읽는다. 문장에 남은 내용, 사라진 공간·시간 정보를 가른다. 설명의 충분성과 모델 능력을 동시에 바꾸면 원인을 하나로 정할 수 없음을 설명한다.
- 경계·부록: 캡션은 무음·채널 위상 제거와 같은 통제가 아니다. 모든 문장은 공간 정보를 잃는다는 주장도 하지 않는다. 도입 알람 장면을 쓸 경우 ‘발표자 설명용’으로 표시한다.
- 다음 연결: 이런 질문을 실제 모델에 물었을 때의 보고 점수는 어느 기준과 비교해야 하는가?

### S69. STAR-Bench의 공간 과제와 우연 기준

- 청중 질문: 벤치마크의 낮은 평균은 어떤 종류의 질문에서 나온 것인가?
- 남길 한 문장: 보고 모델의 세 공간 과제 AA는 40.87–48.97%로 우연 기준 33.33%보다 높으며, 최신 모든 모델에 대한 결론은 아니다.
- 화면·근거: P24 Table 2의 Gemini 2.5 Pro(2025년 6월 업데이트)/Random Guess, Localization·Relation·Trajectory 세 열. AA=40.87/48.97/45.28%, 우연 기준=각33.33%. 같은 세 선택지 공간 과제끼리 읽고 모델 버전을 화면에 남긴다.
- 설명 순서: 평가 모델의 버전과 질문 형식을 먼저 밝힌다. 우연 기준선을 읽고 과제별 점수를 비교한다. AA는 반복 실행 평균이고 ACR는 매번 맞힌 문항 비율임을 한 문장으로 구별한다.
- 경계·부록: 숫자는 효과의 통계적 유의성이나 phase 사용을 입증하지 않는다. BAT의 0점 등을 기전 붕괴의 증거로 크게 쓰지 않는다. 서로 다른 입력 지원·전처리·응답 형식 적합성이 개입할 수 있다. 전체 19모델 순위표와 ACR는 부록이다.
- 다음 연결: 통제된 질문과 별도로, 실제 착용자 환경에서 ‘응답할 발화’를 고르는 문제를 보자.

### S70. 주변 대화와 기기 대상 발화를 구별하기

- 청중 질문: 인식 가능한 말이 들렸다는 이유만으로 음성 기기가 응답해야 하는가?
- 남길 한 문장: 실제 청취 판단에는 들린 말의 내용뿐 아니라 응답 대상인지 고르는 문제가 있다.
- 화면·근거: P25 WearVox Fig. 1의 side-talk rejection 부분. 착용자와 주변 화자를 구별하되 연구 범위 밖의 도구 실행·검색·번역 흐름은 화면에 넣지 않는다. 예측 답변을 새로 꾸미지 않는다.
- 설명 순서: 기기를 향한 발화와 주변 사람끼리의 대화를 대비한다. 내용 인식은 두 경우 모두 가능해도 요구 출력은 응답/비응답으로 다름을 설명한다. 웨어러블 실제 녹음과 앞 합성 공간 QA의 평가 조건 차이를 짚는다.
- 경계·부록: WearVox를 앞 공간 LLM들의 실환경 전이 시험이라고 소개하지 않는다. 실제 사용 조건이라는 별도 검증 축이다. 주변 대화의 의도를 음향만으로 언제나 유일하게 알 수 있다고도 하지 않는다.
- 다음 연결: 이 사례에서 추가 채널을 실제로 어떻게 제공했고, 무엇이 개선되었는가?

### S71. WearVox의 입력 조건과 응답 대상 판단

- 청중 질문: 이 논문의 ‘다채널’은 어떤 신호를 더 받는다는 뜻인가?
- 남길 한 문장: 이 SC/MC 시스템 비교는 side-talk 판단의 이득을 보이지만 순수 위상 단서의 효과는 분리하지 않는다.
- 화면·근거: P25 Table 4의 SC Wearllama/MC Wearllama, Side Talk Rejection 열만 주표로 둔다. 85.4%→93.9%. 위쪽 평문에 SC=beamformed channel, MC=channel 0+beamformed channel을 쓴다.
- 설명 순서: Fig. 2를 근거로 입력 차이를 말로 설명한 다음 표를 읽는다. 합성 다채널 학습과 실제 WearVox 시험을 구별한다. 같은 종류의 질문에서 추가 채널·시스템 구성이 어떤 이득을 보고했는지 한정한다.
- 경계·부록: 모든 원시 마이크 채널의 동시 입력으로 그리지 않는다. 채널0의 SNR·beamforming·학습 변경이 함께 있으므로 phase-only 통제가 아니다. 초록/서론의 85.6이 아니라 Table 4의 85.4를 사용한다. 다른 응용 과제는 부록 밖 참고로 남긴다.
- 다음 연결: 시스템 출력을 잠시 떠나, 고정된 표현 자체에서 어떤 공간 정보가 읽히는지 묻는다.

### S72. 고정 표현에서 공간 요인이 읽히는가?

- 청중 질문: 같은 음원도 위치·방이 달라질 때 인코더에 어떤 정보가 남는가?
- 남길 한 문장: 선형 판독은 특정 pooling 뒤의 표현에서 정보가 얼마나 쉽게 읽히는지 시험한다.
- 화면·근거: P26 SARL의 실험 프로토콜을 원문 §3·Table 1에 근거해 재구성한다. 단일 음원 10초→모델별 전처리→고정 인코더→평균 pooling→학습 선형 판독기. 음원 방향/거리/사건과 방 RT60/부피/형상을 구별한다.
- 설명 순서: S17의 고정/학습 범위를 회수한다. 범주 과제의 macro-F1과 연속량을 구간화한 판독 점수를 설명한다. 마지막으로 무작위 기준 0, 완전 성능 1의 정규화가 raw accuracy가 아님을 밝힌다.
- 경계·부록: source와 room 과제군은 생성 파이프라인도 달라 순수 요인 난이도만 비교하는 것이 아니다. 하나의 낮은 점수로 pooling 전 정보나 비선형 판독 가능성까지 부정하지 않는다. 수식과 모델별 입력 목록은 부록이다.
- 다음 연결: 이 고정된 시험에서 접근성과 단순한 반응 민감도는 어떻게 달라지는가?

### S73. 접근성과 민감도는 다른 측정이다

- 청중 질문: 입력 변화에 표현이 크게 움직이면 그 속성을 정확히 읽을 수 있는가?
- 남길 한 문장: 표현의 변화량과 목표 요인의 판독 가능성은 동일하지 않다.
- 화면·근거: P26 Fig. 2의 세 그룹, 사건 의미 / 위치(방위·고도·거리 평균) / 방 특성(RT60·부피·형상 평균)을 유지한다. 모델별 입력 범례와 정규화 축을 보존한다. Fig. 3은 민감도 정의를 대비하는 부록이며 새 정밀 순위표로 만들지 않는다.
- 설명 순서: 우연 기준과 요인 그룹을 먼저 읽고, 같은 표현도 무엇을 읽느냐에 따라 결과가 달라짐을 설명한다. 이어 perturbation distance는 목표 라벨을 판독한 점수가 아니라는 차이를 묻는다.
- 경계·부록: 서로 다른 mono/binaural/FOA 모델 비교는 학습 목표 하나의 통제가 아니다. 전체 source 평균을 순수 위치 성능이라 부르지 않는다. 이 연구가 시험하지 않은 공간 LLM을 실패 칸에 넣지 않는다.
- 다음 연결: 특정 단서를 바꾸는 최소 자극 실험은 어떤 더 좁은 질문에 답할 수 있을까?

### S74. 잡음 속 표적음의 위상만 바꾼다면?

- 청중 질문: 잡음 속 순음의 양이 위상 관계가 달라지면 고정 표현도 다르게 반응하는가?
- 남길 한 문장: 여기서 측정하는 것은 사람의 탐지 역치가 아니라 세 자극 사이의 임베딩 거리다.
- 화면·근거: P27 §2의 N0, S0N0, SπN0 자극 정의를 최소 도식으로 기획한다. 두 조건은 동일 noise seed를 공유한다. 좌/우 순음의 부호와 noise를 각각 표시하고 원문 기반 재구성임을 밝힌다.
- 설명 순서: noise-only 기준을 제시하고 동위상/역위상 표적을 더한다. 고정 인코더와 pooling을 통과한 후 두 표적 조건이 noise 표현에서 얼마나 떨어지는지 비교한다. 거리 비에 로그를 취한 값이 연구의 BMLD 유사 지표임을 설명한다.
- 경계·부록: 표적의 위상을 바꾸면 오른쪽 혼합 파형과 간섭 무늬도 달라진다. 단일 조작이 내부 위상 비교만 바꾸는 것은 아니다. 사람의 dB threshold 및 EC 모델 기준과 임베딩 거리비를 같은 성능 척도로 등치하지 않는다.
- 다음 연결: 주파수와 SNR를 고정한 한 조건부터 실제 결과를 읽는다.

### S75. 고정 조건의 위상 변화와 표현 거리

- 청중 질문: 모델별 양의 반응이 보이면 모두 사람처럼 잡음 속 소리를 더 잘 듣는가?
- 남길 한 문장: 양의 거리비는 이 표현에서의 반응이며 인간 청취나 QA 성공을 직접 뜻하지 않는다.
- 화면·근거: P27 Table 1, 500 Hz·SNR −14 dB. Spatial-AST 6.8, DSpAST 7.0, GRAM-T 2.1, WavJEPA 0.5 dB와 원표 유의성 별표를 보존한다. 입력/후처리 조건과 반복 자극·검정 각주를 붙인다.
- 설명 순서: S74의 두 거리를 회수하고 양수/음수의 뜻을 설명한다. 선택 모델들의 반응을 같은 자극에서 읽되 내부 전처리는 다름을 표시한다. 왼쪽 채널만 쓰는 mono 대조군은 입력이 변하지 않아 구성상0이라는 점을 말한다.
- 경계·부록: EC=15.7을 인간 실측 역치나 모델의 목표 정답으로 제시하지 않는다. 한 조건의 값으로 주파수 전역 일반화를 하지 않는다. 전체 모델/주파수 곡선과 pooling 비교는 부록으로 보낸다.
- 다음 연결: 이 반응을 설명할 수 있는 다른 신호 단서를 바꾸면 무엇이 남는가?

### S76. 단서 변경 실험으로 설명 범위를 좁히기

- 청중 질문: 위상 조건 반응이 다른 간섭 단서에도 의존한다면 어디까지 주장할 수 있는가?
- 남길 한 문장: 통제 자극과 ablation은 가능한 설명을 좁히지만 내부 기전을 유일하게 복원하지는 않는다.
- 화면·근거: P27 Fig. 3에서 원신호/고역통과/대역 에너지 조정/포락선 vocoding 조건을 비교한다. 한 대표 행 GRAM-T를 먼저 읽는다. 20개 주파수×SNR cell의 유의한 반응 비율이며 unmasking과 reversal 색을 분리한다.
- 설명 순서: 무엇을 변형했는지 먼저 설명한다. 예를 들어 vocoded 75%는 50% unmasking+25% reversal이며 정확도75%가 아님을 읽는다. 파형 변형의 부수 변화도 있으므로 ‘phase 사용 증명’과 ‘phase가 전혀 없음’ 양쪽 단정을 피한다.
- 경계·부록: 이후 제안할 채널별 대조·동일 parser·추가 pooling/판독 실험은 미실행이다. 이 결과는 배열 일반화나 모든 질문 응답 모델의 인과 추론을 시험하지 않는다. 상세 유의성 검정은 부록이다.
- 다음 연결: 이제 각 논문이 처음의 질문에 어느 입력과 근거로 답했는지 회수한다.

### S77. 처음의 알람 질문에 대한 연구별 답

- 청중 질문: 처음의 알람 문제를 이 발표는 실제로 어디까지 설명했는가?
- 남길 한 문장: 문헌은 하나의 완성 모델이 아니라 서로 다른 질문·출력·검증 조건을 채운다.
- 화면·근거: 상위 설계 I의 확정 여섯 행을 사용한다. P02 위치 후보 / P11 목표 DOA·활성 수 / P09 문장 선택 / P17 음원별 기술 / P22 시간 QA / P24–P27 서로 다른 평가. 각 행의 입력·출력·평가 조건과 빈칸을 그대로 회수한다.
- 설명 순서: S02 질문을 회수한다. 청중에게 ‘알람의 방향 숫자’와 ‘알람 뒤에 난 소리’의 출력 차이를 말해 보도록 한다. 대표 결과가 검증한 조건과 아직 미보고인 조건을 각각 하나씩 확인한다.
- 경계·부록: ‘검증됨(조건 명시) / 미보고 / 해당 없음’을 사용한다. 이기지 못한 모델로 단순 색칠하지 않는다. 서로 다른 배열·데이터·판독을 한 성능선으로 연결하지 않는다. 그림은 문헌 종합이며 새 실험 데이터가 아니다.
- 다음 연결: 연구 설계에서 다음에 요구할 증거를 세 질문으로 정리하고 마친다.

### S78. 청각 판단을 주장할 때 필요한 세 질문

- 청중 질문: 다음 공간 오디오 논문을 읽거나 설계할 때 무엇부터 확인해야 하는가?
- 남길 한 문장: 어떤 입력으로 어떤 질문에 답했는지, 그리고 그 답을 뒷받침하는 실험이 무엇인지 함께 말해야 한다.
- 화면·근거: 세 문장만 둔다. ‘무엇을 관측했나?’ ‘정확히 무엇을 출력했나?’ ‘어떤 비교가 그 주장을 지지하나?’ 아래 한 줄에 새 음원·방·배열·질문 조합·실측 조건은 각각 다른 전이 축이라고 덧붙인다.
- 설명 순서: 위치 판독, 목표 선택, 장면·시간 판단에서 확인한 성과를 인정한다. 이어 일반화와 청각 단서의 근거가 과제마다 다르게 남는다고 정리한다. 더 큰 모델이나 특정 새 구조가 반드시 정답이라는 결론으로 넘어가지 않는다.
- 경계·부록: 인간 같은 위상 처리를 모든 과제 성공의 필요조건으로 요구하지 않는다. 관측된 실패에서 정보 부재를 단정하지 않는다. 기존 연구 가설과 네 실험 제안은 문헌 결과와 분리된 토의 부록으로 보존한다.
- 다음 연결: Q&A에서 원하는 출력·평가 조건을 지정받아 해당 원문 결과나 부록으로 돌아간다. 새로운 논문 목록으로 발표를 다시 시작하지 않는다.
