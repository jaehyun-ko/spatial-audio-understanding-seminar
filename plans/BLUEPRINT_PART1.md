# 상세 제작 명세 1부: S01–S37

기준: 레드팀 수정 후의 78장 구성 중 첫 회차. 이 문서는 제작 지시서이며 실제 슬라이드나 확보한 새 그림을 뜻하지 않는다. 각 카드의 발표문은 핵심 설명의 출발점이고, 카드 전체를 화면에 쓰지 않는다.

근거 ID: P01 Neural-SRP, P02 AGG-RL, P03 MC-SimCLR, P04 CCSR, P05 SFD, P06 GRAM, P07 LAM, P08 AT2SELD, P09 ELSA, P10 SALM, P11 SelectTSL. C로 시작하는 ID는 발표자의 설명용 장면·개념도다. 원문 기반 재구성과 설명용 사고실험을 실제 결과와 구별한다. 확인 전 수치는 이 문서에 채우지 않으며, 결과 장의 최종 행·열은 근거 대장의 같은 P ID와 대조한다.

## A. 공통 문제의식

### S01. 공간 소리를 듣고 판단하는 모델

- 청중 질문: 이번 발표는 소리를 만드는 기술인가, 소리로 주변을 알아내는 기술인가?
- 남길 한 문장: 이 발표는 모델이 청각 입력으로 음원과 공간을 판단하는 방법을 살펴본다.
- 화면·근거: 범위 소개 C01. 간결한 표지에 청각 입력 기반 공간 판단이라는 부제만 둔다. 논문 이름과 구조도는 첫 화면에 나열하지 않는다.
- 설명 순서: “소리를 들은 모델이 무엇이 어디에 있는지 판단하는 연구를 다룹니다. 같은 장면에 서로 다른 질문을 던지면서 각 연구의 설계와 확인된 능력을 비교하겠습니다.”
- 경계·부록: 생성·렌더링·로봇 행동은 독립 주제에서 제외한다. 기술들이 차례로 대체됐다는 역사적 계보를 주장하지 않는다.
- 다음 연결: “먼저 모델이 답해야 할 질문 하나를 실제로 떠올려 보겠습니다.”

### S02. 알람은 어느 쪽에서 울리는가?

- 청중 질문: 말소리와 알람을 알아듣는 것만으로 알람의 위치까지 답할 수 있는가?
- 남길 한 문장: 알람의 방향을 답하려면 소리의 종류를 해당 음원의 위치와 연결해야 한다.
- 화면·근거: 문제 장면 C02. 왼쪽 말소리와 오른쪽 알람, 관측 장치를 보여주고 요구 출력은 한 답인 ‘오른쪽’으로 표시한다. 아직 모델 출력이나 성능 점수를 넣지 않는다.
- 설명 순서: “이 장면에는 말소리와 알람이 함께 있습니다. 모델은 두 소리의 이름을 나열하는 데서 그치지 않고, 알람에 해당하는 방향을 답해야 합니다.”
- 경계·부록: 설명용 정적 장면이며 실제 모델의 성공 예제가 아니다. 동시 음원의 분리 파형을 출력하라는 과제와 구별한다.
- 다음 연결: “그 방향을 알려주는 정보는 녹음된 신호의 어디에 남아 있을까요?”

### S03. 두 채널에 남는 공간 단서

- 청중 질문: 같은 장면을 녹음한 두 채널에서 공간과 관련해 무엇이 달라지는가?
- 남길 한 문장: 채널 사이의 시간·크기·주파수별 차이가 공간 판단의 관측 단서가 된다.
- 화면·근거: 관측 설명 C03. 한 음원의 두 채널 관측을 대응시킨 단일 도식을 사용한다. 시간차와 레벨차를 구별하고 주파수별 차이는 다음 설명의 예고로만 표시한다.
- 설명 순서: “두 채널에는 같은 음원이 서로 다른 관측으로 들어옵니다. 여러 차이 중에서 먼저 도달 시점과 위상에 집중해, 방향 판단의 가장 단순한 관계를 보겠습니다.”
- 경계·부록: 단일 채널에 공간 정보가 전혀 없다고 말하지 않는다. 파형의 크기 하나가 음원의 거리를 유일하게 결정한다는 인상도 피한다.
- 다음 연결: “같은 소리가 두 마이크에 서로 다른 시점에 도착하는 이유부터 살펴보겠습니다.”

### S04. 경로 차이와 도달 시간차

- 청중 질문: 마이크 사이의 시간차는 음원과 마이크의 어떤 관계에서 생기는가?
- 남길 한 문장: 서로 다른 전파 경로 길이가 마이크 사이의 도달 시간차를 만든다.
- 화면·근거: 물리 문제 P02 Fig. 1(a). 알람 하나와 마이크 두 개의 경로를 중심으로 크롭한다. 경로 차이와 도착 시점을 연결하되 원문 그림에 없는 수치를 추가하지 않는다.
- 설명 순서: “이번에는 알람 하나만 남기고 직접 도착하는 경로를 보겠습니다. 두 경로의 길이가 다르면 도달 시점도 달라지며, 그 상대 시간차를 TDoA라고 부릅니다.”
- 경계·부록: 단일 직접음 근사임을 화면에 남긴다. 지연 하나만으로 3차원 방향을 유일하게 정한다는 설명과 자세한 부호 유도는 피한다.
- 다음 연결: “이 시간차는 주파수별 위상에서는 어떤 모습으로 관측될까요?”

### S05. 위상 감김과 지연의 모호성

- 청중 질문: 위상차를 한 번 측정하면 시간차를 곧바로 알 수 있는가?
- 남길 한 문장: 위상은 한 바퀴마다 같은 값으로 돌아오므로 한 주파수의 위상차만으로 지연을 정하기 어렵다.
- 화면·근거: 물리 문제 P02 Fig. 1(b). 주파수에 따른 위상과 감김을 읽는 한 그림을 사용한다. 필요 수식은 Δφ(f) = 2πfτ mod 2π 하나로 제한한다.
- 설명 순서: “같은 지연도 주파수가 달라지면 다른 위상차로 보입니다. 위상이 감기면 서로 다른 지연이 한 주파수에서 같은 위상값을 만들 수 있어, 주파수들을 함께 해석해야 합니다.”
- 경계·부록: 단일 주파수 모호성과 배열 전체의 모든 공간 모호성을 동일시하지 않는다. PHAT 유도와 구현 세부는 부록으로 보낸다.
- 다음 연결: “실제 녹음에서는 이 단순한 직접음 관계에 다른 경로와 소리도 섞입니다.”

### S06. 하나의 관측을 만드는 여러 조건

- 청중 질문: 소리가 작거나 잔향이 많으면 음원이 멀다고 판단해도 되는가?
- 남길 한 문장: 관측 신호에는 거리뿐 아니라 음원 레벨과 방의 전달 특성이 함께 작용한다.
- 화면·근거: 역문제의 모호성 C06. 음원, 직접 경로, 반사 경로, 두 채널 관측을 한 장면에 놓는다. 거리·음원 레벨·방 조건을 별개의 변경 요인으로 표시하되 관측이 완전히 같다는 가짜 파형을 만들지 않는다.
- 설명 순서: “녹음에는 직접음과 반사음, 잡음이 함께 들어옵니다. 작은 소리나 긴 잔향 하나만 보고 거리나 방의 정체성을 단정하기 어려운 이유는 여러 원인이 같은 관측 특징에 영향을 주기 때문입니다.”
- 경계·부록: 모델의 실제 실패 사례가 아닌 관측 조건 설명이다. 방 식별·거리 추정의 세부 단서는 해당 연구에서 필요한 만큼 다시 설명한다.
- 다음 연결: “같은 음원과 방을 두어도, 이번에는 마이크 배치만 바꾸면 어떨까요?”

### S07. 같은 방향, 다른 마이크 배치

- 청중 질문: 음원은 그대로인데 채널 사이의 지연이 달라져도 올바른 방향을 유지할 수 있는가?
- 남길 한 문장: 배열 기하가 바뀌면 같은 방향의 음원도 다른 채널 관계로 관측된다.
- 화면·근거: 배열 변경 문제 C07, P02의 기하 일반화 문제를 참고한 설명용 재구성. 음원·배열 중심·기준 좌표계를 고정한 두 배치를 비교하고, 목표 방향과 관측 지연을 다른 항목으로 표시한다.
- 설명 순서: “여기서는 음원과 방 대신 마이크의 상대 배치만 바꿉니다. 기대하는 방향은 같지만 경로 차이가 달라지므로, 모델은 달라진 관측을 기하에 맞춰 해석해야 합니다.”
- 경계·부록: 원거리 단일 음원 사고실험이라는 조건을 유지한다. 장치 회전과 세계 좌표계 변경을 같은 조작으로 섞지 않는다.
- 다음 연결: “이제 처음의 두 음원 장면에서 모델에 요구하는 중간 출력을 분명히 해보겠습니다.”

### S08. 공간 단서에서 활성 방향 후보로

- 청중 질문: 알람의 방향을 답하기 전에, 소리가 있는 방향들을 먼저 찾을 수 있는가?
- 남길 한 문장: 활성 방향의 후보를 찾는 일과 각 후보를 소리 이름에 연결하는 일은 구별할 수 있다.
- 화면·근거: 과제 분해 C08. C02와 같은 장면을 새 시점으로 재구성하고 요구 출력은 ‘활성 방향 후보 집합’으로 둔다. 소리 이름 없는 방향 후보와 최초의 알람 질문을 대비하는 하나의 개념도를 사용한다.
- 설명 순서: “우선 어느 방향에 소리가 있는지를 출력하는 문제부터 생각하겠습니다. 이 후보에 알람이라는 이름을 연결해야 처음의 질문까지 답할 수 있으므로, 뒤에서는 출력의 요구를 조금씩 바꾸겠습니다.”
- 경계·부록: 모든 실제 시스템이 이 순서의 두 모듈로 구현된다고 주장하지 않는다. 기술의 발전 단계가 아니라 발표를 위한 과제 구분이다.
- 다음 연결: “방향 후보를 비교하려면 각 후보가 예측하는 지연과 실제 관측을 맞춰볼 수 있습니다.”

## B. 위치와 음원별 출력

### S09. 후보 방향과 관측 지연의 일치

- 청중 질문: 여러 채널의 지연 정보를 어떻게 한 방향의 점수로 모으는가?
- 남길 한 문장: 후보 위치나 방향이 예측하는 채널 관계와 관측의 일치를 모아 공간 응답을 만든다.
- 화면·근거: 계산 직관 C09, P01·P02의 위치 추정 문제를 참고한 개념도. 후보 하나가 예측한 지연과 여러 마이크 쌍의 관측을 대응시킨다. GCC/SRP와 IPDnet의 이름은 작은 비교 주석으로만 둔다.
- 설명 순서: “후보 방향을 하나 정하면 배열 기하로부터 기대하는 지연 관계를 계산할 수 있습니다. 기존 방법은 이러한 일치를 계산하고, IPDnet 같은 방법은 직접음 IPD라는 중간 목표를 학습합니다.”
- 경계·부록: IPDnet은 기초 비교 사례이며 추가 중심 논문으로 확대하지 않는다. MUSIC의 부분공간 유도와 모든 고전 방법의 분류는 부록으로 보낸다.
- 다음 연결: “관측이 복잡할 때 이 공간 응답 자체를 학습하면 어떤 변화가 생길까요?”

### S10. 복잡한 관측에서의 위치 응답

- 청중 질문: 반사음 등이 섞인 실제 녹음에서 위치 응답은 어떻게 달라 보이는가?
- 남길 한 문장: Neural-SRP의 실제 응답 예시는 학습한 공간장이 기존 SRP와 어떻게 달라지는지 보여준다.
- 화면·근거: 정성적 문제·결과 P01 Fig. 1. 위 NeuralSRP+, 아래 SRP의 응답을 하나의 원문 비교 그림으로 제시한다. 음원과 마이크 표시를 먼저 설명하고 같은 위치를 대응시켜 읽는다.
- 설명 순서: “같은 녹음에서 두 방법이 만든 공간 응답을 비교하겠습니다. 실제 녹음에 적응한 NeuralSRP+의 예시라는 조건을 먼저 확인하고, 음원 근처와 다른 영역의 응답을 살펴보겠습니다.”
- 경계·부록: 한 그림으로 전체 성능이나 무적응 실환경 전이를 입증하지 않는다. 적응 전후 모든 변형의 정량 비교는 별도 근거를 확보해 부록에 둔다.
- 다음 연결: “쌍별 응답을 학습해 합산한 방법이 실제 위치 오차도 줄였는지 확인하겠습니다.”

### S11. Neural-SRP의 실제 녹음 평가

- 청중 질문: 쌍별 응답을 학습한 방법이 실제 녹음의 위치 오차를 줄였는가?
- 남길 한 문장: Recorded 4에서는 실녹음에 적응한 NeuralSRP+의 위치 오차가 SRP보다 낮았다.
- 화면·근거: 결과 P01 Table I의 Recorded 4 한 조건. SRP 1.19 m와 NeuralSRP+ 0.77 m를 주표로 비교하고, 250개 실녹음 적응과 한 방의 정지 단일 음성 조건을 표시한다.
- 설명 순서: “쌍별 위상과 좌표, 방 크기로 학습한 응답을 합산하는 방법의 결과입니다. 이 조건에서는 오차가 줄었지만 NeuralSRP+는 실제 녹음으로 적응했으므로, 처음 만난 환경에서 무적응으로 얻은 성과라고 읽으면 안 됩니다.”
- 경계·부록: Fig. 3 전체 구조와 Recorded 6 결과는 부록이다. 후보 좌표는 학습 목표 구성에 쓰며 추론 입력이 아니라는 주석을 유지한다.
- 다음 연결: “고정된 위치 격자를 예측하는 방식과 달리, 후보 방향 목록 자체도 바꾸고 싶다면 어떨까요?”

### S12. 배열과 후보 격자의 서로 다른 변화

- 청중 질문: 마이크 배치를 바꾸는 것과 모델에 물어볼 방향 목록을 바꾸는 것은 같은 문제인가?
- 남길 한 문장: 배열 기하와 후보 방향 격자는 독립적으로 달라질 수 있는 조건이다.
- 화면·근거: 문제 P02 §2.2 기반 재구성. 한 배열에서 후보 방향 간격을 바꾸는 장면을 주그림으로 둔다. S07의 배열 변경은 작은 문장으로만 회수해 두 조건을 구별한다.
- 설명 순서: “앞에서는 녹음하는 마이크 배치를 바꿨지만, 여기서는 같은 녹음에 물어볼 방향 목록을 바꿉니다. 출력 칸이 고정된 모델과 후보 방향을 조건으로 받는 모델은 이 요구를 다르게 다룹니다.”
- 경계·부록: 후보 수 증가를 각도 정확도의 자동 향상으로 표현하지 않는다. 임의 격자와 임의 실제 배열 모두에 대한 보장도 주장하지 않는다.
- 다음 연결: “AGG-RL은 오디오와 마이크 기하에 더해 후보 방향도 모델에 제공합니다.”

### S13. AGG-RL의 오디오·기하·후보 방향 표현

- 청중 질문: 관측 신호와 새 후보 방향을 어떻게 비교 가능한 표현으로 만드는가?
- 남길 한 문장: AGG-RL은 오디오·배열 기하·후보 방향을 함께 사용해 후보별 공간 응답을 계산한다.
- 화면·근거: 방법 P02 Fig. 2. 전체 층을 읽지 않고 두 표현의 정합과 입력 경로를 중심으로 크롭한다. LNuDFT는 주파수 단서, rMPE는 상대 기하 문제와 연결하는 주석만 둔다.
- 설명 순서: “그림에서 먼저 오디오와 마이크 좌표가 들어오는 경로, 후보 방향이 들어오는 경로를 나눠 보겠습니다. 이들이 만드는 표현을 비교해 각 후보의 응답을 계산하는 것이 이번 설계의 핵심입니다.”
- 경계·부록: LNuDFT·rMPE를 학습 목표라고 부르지 않는다. 모든 내부 층과 손실 유도는 부록이며 구조만으로 일반화 성능을 결론내리지 않는다.
- 다음 연결: “이제 설계 의도가 실제로 평가한 새 배열 조건에서 어떤 결과를 냈는지 확인하겠습니다.”

### S14. AGG-RL의 미관측 채널 수 조건

- 경계·부록: 모든 배열 일반화의 보장으로 읽지 않는다. Proposed 전체 시스템, Dynamic-S 상세, Table 4 격자 수와 Table 5 비용은 별도 부록이다.
- 다음 연결: “위치를 찾았다면, 각 위치에 어떤 종류의 소리가 있는지도 함께 출력할 수 있을까요?”

### S15. 위치 추정과 음원별 사건 검출

- 청중 질문: 방향을 찾는 모델과 소리의 종류·방향을 함께 찾는 모델의 출력은 어떻게 다른가?

- 경계·부록: 고정 클래스 SELD를 자유 어휘 질의나 자유형 답변과 동일시하지 않는다. 평가 지표의 세부 정의는 실제 결과를 읽을 때 소개한다.
- 다음 연결: “이런 출력을 배우는 연구들은 같은 형식의 오디오를 입력으로 쓰고 있을까요?”

- 경계·부록: FOA를 마이크 네 개라고 설명하지 않는다. 모든 모델에 좌표나 깊이가 추론 입력으로 들어간다는 보편 도식도 피한다.
- 다음 연결: “입력 조건을 구별했으니, 이제 어떤 부분을 학습하고 무엇을 고정한 채 평가하는지 정하겠습니다.”

### S18. MC-SimCLR의 반복 관측

- 청중 질문: 소리가 이어지는 동안 달라지는 파형에서 어떤 공간 관계를 일관되게 배우게 할 수 있는가?
- 남길 한 문장: MC-SimCLR은 정지 음원을 가정한 같은 다채널 녹음의 시간 구간들을 양성 쌍으로 사용한다.
- 화면·근거: 문제·핵심 방법 P03 Fig. 1의 학습 과제 기반 재구성. 하나의 다채널 녹음에서 두 시간 구간을 고르는 모습을 주그림으로 둔다. 두 구간 모두 채널 관계를 포함함을 표시한다.
- 설명 순서: “음원이 움직이지 않는 동안 같은 녹음의 서로 다른 구간을 관측한다고 생각하겠습니다. 이 방법은 그 구간들을 가깝게 학습하면서 반복 관측에 남는 정보를 표현에 담으려 합니다.”
- 경계·부록: 임의의 단일 채널 둘을 양성 쌍으로 묶는다고 설명하지 않는다. 정지 음원 가정을 이동 장면까지 자동 확장하지 않는다.
- 다음 연결: “그 목표가 사건과 방향을 읽는 데 도움이 됐는지는 후속 판독으로 확인해야 합니다.”

### S19. 대조 학습 뒤의 사건·방향 판독

- 청중 질문: 같은 녹음의 구간을 가깝게 만든 표현에서 사건 종류와 방향을 각각 읽을 수 있는가?

- 설명 순서: “이번에는 같은 인코더를 고정한 채 사건 종류와 방향을 각각 읽습니다. 추가 증강이 없는 사전학습과 사전학습하지 않은 조건을 비교하면, 두 판독의 개선을 서로 다른 지표로 확인할 수 있습니다.”

- 다음 연결: “서로 다른 구간을 가깝게 만드는 대신, 관측 일부를 복원하게 하면 무엇을 배우게 될까요?”

### S20. CCSR의 복원 목표와 마스킹

- 청중 질문: 일부 관측을 가렸을 때 어떤 채널 관계를 이용해 복원하도록 학습할 수 있는가?
- 남길 한 문장: CCSR은 STFT 관측의 복원을 학습하며 공간·스펙트럼 분기의 마스킹을 다르게 구성한다.
- 화면·근거: 문제·핵심 방법 P04 Fig. 1 기반 ‘복원 목표 개념도’. 관측 일부와 복원 대상을 보여주는 단일 도식에 공간 분기의 양 채널 동일 프레임 마스크, 스펙트럼 분기의 상보 마스크를 구별한다.
- 설명 순서: “먼저 어떤 관측을 정답으로 복원하는지 보겠습니다. 두 분기는 가리는 방식이 다르므로, 한 채널의 빈칸을 다른 채널로 채우는 단순 그림을 전체 구현이라고 읽으면 안 됩니다.”
- 경계·부록: 단순화한 그림에는 복원 목표 개념도라는 표기를 남긴다. 세부 마스크 구조는 부록이며, 복원 성공만으로 원하는 공간 정보를 쉽게 판독한다고 단정하지 않는다.
- 다음 연결: “따라서 복원 손실과 별도로, 실제 후속 공간 과제에서의 효과를 보겠습니다.”

### S21. CCSR의 후속 과제 적응

- 청중 질문: 복원 과제로 배운 초기 표현이 실제 공간 과제를 학습할 때 도움이 되는가?
- 남길 한 문장: CCSR의 전체 미세조정은 이 조건의 TDoA 오차를 줄였지만 모든 공간 지표를 함께 개선하지는 않았다.
- 화면·근거: 결과 P04 Table III의 학습 방 8개 조건. scratch 0.40 samples와 full fine-tuning 0.28 samples의 TDoA 오차를 주표로 비교한다. 고정 인코더 수치를 섞어 하나의 향상량으로 만들지 않는다.
- 설명 순서: “여기서는 후속 조건에서 처음부터 학습한 경우와 전체 미세조정한 경우를 비교합니다. TDoA는 개선됐지만 C50 오차는 1.14 dB에서 1.21 dB로 증가해, 모든 지표가 함께 좋아지지는 않았습니다.”
- 경계·부록: C50 반례를 짧은 주석으로 남긴다. frozen의 TDoA 1.49와 T60 상세는 부록이며, 전체 적응 결과를 고정 표현의 선형 접근성으로 표현하지 않는다.
- 다음 연결: “복원의 대상은 파형 관측뿐 아니라 채널 간 관계를 나타내는 통계가 될 수도 있습니다.”

### S22. LAM의 잠재 음향지도

- 청중 질문: 음원의 정답 방향을 주지 않고도 채널 관계를 설명하는 지도를 학습할 수 있는가?
- 남길 한 문장: LAM은 채널 간 공분산 관측을 복원하도록 잠재 음향지도를 학습한다.
- 화면·근거: 문제·핵심 방법 P07 Fig. 2의 관측·잠재 지도·복원 관계만 사용한다. 공분산을 채널 간 이차 관계로 먼저 풀어 설명하고, 잠재 지도가 정답 DOA 라벨과 다른 역할임을 표시한다.
- 설명 순서: “모든 장면에 방향 정답을 붙이는 대신, 실제로 관측한 채널 관계를 설명하도록 학습할 수 있습니다. LAM에서는 그 관측을 복원하는 과정에 잠재 음향지도가 들어갑니다.”
- 경계·부록: 공분산 복원용 지도를 모든 의미 과제에 재사용하는 범용 표현이라고 부르지 않는다. 전체 수학 유도와 복원 경로의 내부 층은 부록이다.
- 다음 연결: “이 지도가 실제 방향을 얼마나 정확하고 빠짐없이 읽어내는지 확인하겠습니다.”

### S23. LAM의 검출 임계값과 위치 판독

- 청중 질문: 같은 지도와 판독기라도 검출 임계값을 바꾸면 오차와 재현율이 달라지는가?
- 남길 한 문장: 한 모델의 위치 오차와 재현율은 검출 임계값에 따라 함께 읽어야 한다.
- 화면·근거: 결과 P07 Fig. 3에서 UpLAM+GRU-MHSA의 임계값별 LE–LR 곡선만 주근거로 선택한다. STARSS dev-test-sony 조건, 기본 임계값 0.5, LE는 낮게·LR은 높게 읽는 방향을 표시한다.
- 설명 순서: “여기서는 두 모델의 우열이 아니라 같은 모델의 검출 기준을 바꿉니다. 놓치는 음원과 위치 오차가 어떻게 함께 달라지는지 보면서, 기본 임계값에서 얻은 결과의 의미를 확인하겠습니다.”
- 경계·부록: 곡선의 여러 점을 서로 다른 모델로 설명하지 않는다. Table 2의 모델 비교는 부록이며, 이 결과를 음원 종류나 자연어 이해로 확대하지 않는다.
- 다음 연결: “관측을 복원하는 목표와 달리, 깨끗한 공간 특징을 명시적인 정답으로 줄 수도 있습니다.”

### S24. SFD의 깨끗한 공간 특징

- 청중 질문: 잡음과 잔향이 섞인 입력에서 어떤 공간 정보를 남기도록 가르칠 수 있는가?
- 남길 한 문장: SFD는 오염된 바이노럴 입력으로 깨끗한 신호의 공간 특징을 예측하도록 사전학습한다.
- 화면·근거: 문제·핵심 방법 P05 Fig. 1의 입력·교사 목표 부분. 오염된 입력과 깨끗한 목표의 관계를 하나의 그림으로 보여준다. 서로 다른 특징 목표가 별도 학습 변형이라는 점을 표시한다.
- 설명 순서: “이 방법은 모델이 복원할 대상을 원래 파형 전체 대신 공간 특징으로 정합니다. 깨끗한 신호에서 얻은 목표를 오염된 입력으로 예측하게 한 뒤 DOA 과제에 적응합니다.”
- 경계·부록: GCC·GCC-PHAT·CPS 위상·ILD/IPD를 모두 한 손실로 합쳐 학습했다고 설명하지 않는다. 세부 목표 수식은 해당 결과 해석에 필요한 것만 남긴다.
- 다음 연결: “이런 목표 선택이 같은 DOA 미세조정 조건에서 어떤 차이를 만들었을까요?”

### S25. SFD의 DOA 미세조정 결과

- 설명 순서: “여기서는 라벨 시간과 백본을 맞추고 초기화만 비교하겠습니다. 사전학습 이후 인코더도 DOA에 맞춰 바뀌므로, 이 결과는 적응에 유용한 초기 표현의 증거로 읽어야 합니다.”
- 경계·부록: Table 2의 1시간·10시간 표기 충돌 때문에 그 표는 사용하지 않는다. 10분 패널과 다른 변형은 부록이며 서로 다른 데이터 조건의 수치를 섞지 않는다.
- 다음 연결: “공간 특징을 직접 가르치는 것과 달리, 이미 배운 소리 의미를 공간 판단에 연결하는 선택도 있습니다.”

### S26. 의미 사전학습과 SELD의 결합 위치

- 청중 질문: 소리 종류를 잘 구별하는 사전학습 특징은 공간 판단 과정의 어디에 제공해야 하는가?
- 남길 한 문장: AT2SELD는 의미 사전학습과 공간 예측의 결합 위치를 설계 선택으로 다룬다.
- 화면·근거: 문제·핵심 방법 P08 Fig. 25 기반 재구성. 같은 SELD 출력에 의미 특징을 서로 다른 깊이에서 연결하는 선택을 하나의 비교 도식으로 보여준다. 전체 모델 백본은 반복하지 않는다.
- 설명 순서: “앞의 SELD는 소리 종류와 위치를 함께 출력했습니다. 이 연구는 일반 오디오 태깅에서 얻은 의미 정보를 그 예측 과정의 어디에 연결하는 것이 유용한지 묻습니다.”
- 경계·부록: 의미 분류기가 정확하면 음원과 방향의 대응도 자동으로 해결된다고 주장하지 않는다. 고정 클래스 SELD 적응을 자유 어휘 질의응답과 구별한다.
- 다음 연결: “의미 특징을 연결하지 않은 조건과 연결한 조건을 같은 평가에서 비교해 보겠습니다.”

### S27. AT2SELD의 결합 설계 비교

- 청중 질문: 의미 특징의 결합 위치를 바꾸면 같은 SELD 과제에서 무엇이 달라지는가?
- 남길 한 문장: 강한 dropout을 쓴 Stage 3에서는 late-only 결합이 no-stitch보다 낮은 SELD 점수를 보였다.
- 화면·근거: 결과 P08 Table 12. 같은 Stage 3 조건의 no-stitch 0.708과 late-only 0.624를 주표로 비교한다. 낮을수록 좋은 지표임을 표시하고, 강한 dropout 아래의 기준 성능 회복이라는 맥락을 함께 둔다.
- 설명 순서: “이 차이는 원문의 특정 학습 단계와 dropout 조건에서 읽어야 합니다. 그 안에서 late-only 결합이 점수를 낮췄다고 말할 수 있지만, 의미 결합이 모든 학습 조건에서 우월하다는 결론은 아닙니다.”
- 경계·부록: 전체 설정 탐색과 다른 학습 단계는 부록이다. 다른 조건의 최상위 행을 이번 기준선과 짝짓거나 범용 표현의 성과로 확대하지 않는다.
- 다음 연결: “지금까지의 과제별 적응과 구별해, 하나의 고정 표현을 여러 판단에 사용하는 평가를 보겠습니다.”

### S28. GRAM의 복합 공간 장면

- 경계·부록: 복합 장면을 학습했다는 사실만으로 모든 다중 음원 관계를 판단한다고 주장하지 않는다. 장면 생성과 실제 녹음 평가의 역할을 분리한다.
- 다음 연결: “그 관측을 어떻게 학습하고, 고정된 특징을 어떤 방식으로 읽을까요?”

### S29. GRAM의 마스킹 학습과 고정 판독

- 청중 질문: 여러 과제의 정답을 모두 직접 학습하지 않고도 공통 표현을 준비할 수 있는가?

- 설명 순서: “사전학습에서 모델이 받는 과제와 후속 평가에서 판독기가 받는 정답은 다릅니다. 고정 특징 평가를 중심으로 읽되, 원문에 있는 전체 미세조정 비교는 별도 조건으로 구분하겠습니다.”

- 다음 연결: “이 고정 표현에서 위치 같은 공간 요인을 실제로 얼마나 읽을 수 있는지 확인하겠습니다.”

### S30. GRAM의 고정 표현 공간 판독

- 청중 질문: 고정 표현의 DOA 오차 분포를 입력 형식이 다른 모델 사이에서 어떻게 읽어야 하는가?

- 다음 연결: “이제 여섯 학습 목표를 비교하되, 실제로 어떻게 적응하고 무엇을 평가했는지도 함께 보겠습니다.”

### S31. 학습 목표와 확인한 재사용 범위

- 청중 질문: 앞의 방법들이 모두 같은 종류의 범용 공간 표현을 입증한 것인가?

- 경계·부록: 인코더마다 과제·입력·판독기가 다른 숫자를 나란히 등수로 만들지 않는다. 전체 비교 수치와 모든 목표 변형은 부록으로 보낸다.
- 다음 연결: “지금까지 수치나 클래스 이름으로 읽던 표현을, 소리와 공간을 함께 말하는 문장에도 대응시킬 수 있을까요?”

### S34. SALM의 의미와 공간 분기

- 청중 질문: 같은 소리가 위치만 바뀌었을 때 의미와 공간 표현은 각각 어떻게 달라져야 하는가?
- 남길 한 문장: SALM은 의미 정보와 공간 정보를 분리해 언어 표현과 정렬하는 설계를 사용한다.
- 화면·근거: 문제·핵심 방법 P10 Fig. 1 기반 재구성. 소리 종류는 유지하고 위치만 바꾼 두 관측과 두 분기의 역할을 하나의 그림으로 연결한다. 전체 손실 항목은 나열하지 않는다.
- 설명 순서: “같은 알람을 다른 위치로 옮기면 소리의 종류는 유지되지만 공간 속성은 바뀝니다. SALM은 이 차이를 표현의 분리와 언어 정렬이라는 설계 선택으로 다룹니다.”
- 경계·부록: 두 분기를 만들었다는 사실만으로 완전한 요인 분리를 입증했다고 말하지 않는다. 임베딩 편집은 본문의 파형 생성 성과로 쓰지 않는다.
- 다음 연결: “같은 SALM에서 정렬 목표를 하나 더하면 검색과 위치 판독에 어떤 변화가 생기는지 보겠습니다.”

### S35. SALM의 정렬 목표 비교

- 청중 질문: 같은 SALM에 대조 정렬 목표를 추가하면 검색과 위치 판독이 함께 달라지는가?
- 남길 한 문장: 이 SALM 비교에서는 추가 정렬 목표와 함께 검색 점수와 위치 오차가 모두 개선됐다.
- 화면·근거: 결과 P10 Table 1의 sClotho. L_sCL+L_DOA와 여기에 L_CL을 추가한 두 행만 비교한다. T2A R@1은 9.1%/10.5%, A2T R@1은 9.6%/10.4%, 위치 오차는 1.8°/1.6°로 제시한다.
- 설명 순서: “다른 모델의 순위가 아니라 같은 SALM의 학습 목표 한 가지를 비교합니다. 검색 점수는 높아지고 위치 오차는 낮아졌지만, 이는 같은 원문 조건에서 관측한 변화입니다.”
- 경계·부록: 두 검색 방향을 정의하고 지표의 좋은 방향을 표시한다. 실측 SRIR·표현 편집·다른 모델 순위는 부록이며, 자연어 복합 추론의 증거로 확대하지 않는다.
- 다음 연결: “문장 후보 중 맞는 것을 찾는 대신, 문장으로 지정한 소리의 위치만 직접 출력할 수도 있습니다.”

### S36. 원하는 소리만 위치를 찾기

- 청중 질문: 여러 활성 음원 중 요청한 목표에 해당하는 것만 찾아 위치를 출력할 수 있는가?
- 남길 한 문장: SelectTSL은 모든 음원의 위치 대신 지정한 목표의 활성 수와 위치를 판단한다.
- 화면·근거: 문제 P11 Fig. 1. 전체 활성 음원과 질의에 해당하는 목표를 대비한다. 요구 출력은 목표 수와 DOA로 명시하고, 텍스트 또는 예시 오디오가 목표를 지정하는 입력임을 표시한다.
- 설명 순서: “앞의 정렬에서는 오디오와 문장의 대응을 평가했지만, 여기서는 요청한 소리의 위치를 직접 출력합니다. 목표가 없거나 여러 개일 수도 있으므로, 선택과 활성 수 판단도 과제의 일부가 됩니다.”
- 경계·부록: 파형을 분리해 생성하는 과제로 소개하지 않는다. full model의 텍스트·예시 오디오 조건을 텍스트만 쓰는 시스템으로 축약하지 않는다.
- 다음 연결: “이 목표 판단에서 채널 간 위상 정보를 강화한 경로가 어떤 역할을 했는지 확인하겠습니다.”

### S37. SelectTSL의 위상 경로 기여

- 청중 질문: 목표를 지정한 조건을 유지했을 때 IPD 경로가 판단 성능에 기여하는가?
- 남길 한 문장: SelectTSL의 IPD Enhancer 제거 조건에서는 각도 오차가 증가하고 F1이 감소했다.
- 화면·근거: 결과 P11 Table VI의 Full과 A1 한 비교. MAE는 0.98°/2.10°, F1은 0.96/0.83으로 표시한다. 같은 목표 입력 조건을 명시하고 Fig. 2 전체 구조는 넣지 않는다.
- 설명 순서: “같은 목표 입력을 둔 채 IPD Enhancer를 제거한 조건을 비교하겠습니다. 오차와 F1의 변화는 해당 경로의 기여를 보여주지만, 다른 입력 단서의 도움까지 없앴다는 뜻은 아닙니다.”
- 경계·부록: A4 직접 입력과 OSPAT는 부록이다. MAE는 true positive 조건이며, Table III의 MOTA*·Recall 불일치와 실측 RIR 정적 합성이라는 범위를 유지한다.
- 다음 연결: “다음 회차에서는 같은 공간 정보를 질문에 맞는 답변으로 읽는 방식과 그 조건을 살펴보겠습니다.”
