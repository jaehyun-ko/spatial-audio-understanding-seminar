# 공간 소리를 듣고 판단하는 모델: 질문 중심 발표 설계

갱신: 2026-09-11 · 현재 구성: **본문 S01–S48 + 근거 부록 S49–S78 = 78장** · 핵심 문헌 27편

이 문서는 현재 조립된 발표의 설명 구조를 기록한다. 순서와 제목의 기준은 [CAUSAL_DECK_ORDER.json](plans/CAUSAL_DECK_ORDER.json)과 [slides.md](slides.md)다. 원문 27편을 차례로 소개하는 구성이 아니라, **고정 계산의 어떤 부분을 학습하고, 무엇을 표현에 남겨, 어떤 토큰으로 전달하며, LLM이 실제로 사용하게 할 것인가**를 설명한다. 산출물·내보내기 상태는 [README](README.md)를 따른다.

이전 상세 계획은 [보관본](plans/archive/NARRATIVE_PLAN.pre-causal-2026-09-11.md)에 그대로 남겼다. 이전 42장 구조도 [ACADEMIC_STRUCTURE 보관본](plans/archive/ACADEMIC_STRUCTURE.pre-causal-2026-09-11.md)에 보존했다. 두 보관본의 번호·운영 시간·제작 단계 문장은 현재 구성의 명세가 아니다.

## 1. 중심 질문과 설명 방식

**마이크 관측에 담긴 공간 단서가 LLM의 답변까지 전달되고 사용되려면 어떤 조건이 필요한가?**

청중은 기본적인 머신러닝을 아는 대학원 세미나 청중이다. 공간 음향, 표현 판독, 오디오 토큰과 LoRA의 역할은 필요한 자리에서 설명한다. 제목은 연구 이름보다 질문과 연산을 앞세우고, 논문은 그 질문에 대한 설계 사례와 조건부 근거로 배치한다.

발표의 연쇄는 다음과 같다.

1. **계산:** 후보 위치가 만드는 지연을 예측하고 관측과 비교한다.
2. **학습:** 복잡한 관측에서 쌍별 공간 응답을 학습하되 합산과 최대점 선택은 유지할 수 있다.
3. **표현 보존:** 좌표 출력만 다음 단계로 넘기면 부족한 질문이 있으므로 중간 표현에 무엇이 남는지 검사한다.
4. **토큰 전달:** 인코더의 정보가 시간·음원 구조를 잃지 않고 LLM 입력으로 넘어가는 형식을 정한다.
5. **LLM 활용:** 어댑터 정렬과 LLM/LoRA 적응의 역할을 분리한다.
6. **근거 확인:** 정보를 읽을 수 있다는 것, 전달했다는 것, 답변에 사용했다는 것을 각각 검증한다.

이 순서는 논리적 설명 순서다. SRP→Neural-SRP→AGG-RL→범용 인코더→LLM이 차례로 앞선 방법을 대체했다는 역사적 계보나, 서로 다른 논문 점수의 연속 개선을 뜻하지 않는다. 생성·재생·렌더링·장치 설계·로봇 행동은 독립 주제로 확장하지 않는다. 선택적 최근 문헌 세미나이며 모든 공간 오디오 연구를 망라한 체계적 문헌고찰은 아니다.

## 2. 처음의 장면과 좌표를 끝까지 회수한다

S02에서 음원 종류와 3D 위치를 목표로 정의한다. 두 마이크는 x축 위에 놓고 중점 O를 원점으로 삼는다. 방위각 α는 xy 평면의 +x에서 +y 방향, 고도각 β는 xy 평면에서 +z 방향, 거리 r는 O에서 음원까지다. S03–06은 같은 장면에서 도달 신호, 경로차, 반사와 다른 음원, 마이크 간격 변화만 차례로 보여준다. 모든 애니메이션은 라이트 테마의 설명용 계산이며 실제 모델의 예측 결과가 아니다.

두 마이크의 단일 TDoA로 방위각·고도각·거리를 유일하게 추정했다고 말하지 않는다. Neural-SRP 원문의 2D 위치 실험과 AGG-RL의 DOA 실험도 이 전체 3D 목표와 동일시하지 않는다. 도입의 \(\tau=t_2-t_1\)는 Neural-SRP 표기의 \(\tau_{21}\)이고, S09의 \(\tau_{ij}=t_i-t_j\)와는 첨자 순서를 맞춰 읽는다. 교차상관 역시 같은 채널 순서를 따른다.

후반에는 같은 소리의 위치 변경, 같은 위치의 소리 교체, 사건 순서 교환으로 처음 목표를 회수한다. S16의 기대 조건과 S48의 후속 실험은 검증 전 제안이다. 개별 종류와 위치를 맞히는 것, 같은 음원에 속성을 결속하는 것, 연속 identity를 추적하는 것은 서로 다른 요구다.

## 4. 핵심 전환에서 반드시 보일 계산과 정보

### S08–14: 수식의 어느 자리를 학습하는가

SRP는 후보의 기하적 지연에서 쌍별 관측 상관을 읽고 모든 쌍의 응답을 합산해 최대점을 선택한다. S09는 이 동일한 입력/출력 골격 위에서 쌍 응답 생성만 학습으로 바꾼다. 같은 지연을 만드는 위치들이 능선을 이루므로, Neural-SRP의 한 쌍 타깃은 단일 점 Gaussian이 아니다. S10의 실제 응답 예시와 S11의 실녹음 추가 학습 결과는 각각 정성·정량 근거다.

Neural-SRP 2024는 쌍별 STFT 위상·마이크 좌표·방 크기에서 25×25 2D 위치 응답을 예측한다. 후보 좌표는 타깃 구성에 쓰이며 추론 입력이 아니다. AGG-RL 2026 표의 Neural-SRP는 time-domain GCC-PHAT·Fibonacci DOA 격자·복수 공간 응답으로 수정한 재구현이다. S11의 위치 오차와 S14의 각도 오차는 동일 모델의 연속 성능 곡선이 아니다.

S12의 후보 목록 변경과 S14의 미노출 채널 수 시험은 별도의 일반화 축이다. AGG-RL은 관측·기하 표현과 후보 방향 표현을 비교한다. SRP도 알려진 새 기하와 후보 격자를 분석적으로 처리할 수 있으므로, 기하 변경만을 신경망 도입의 필연적 이유로 만들지 않는다. IPDnet은 직접 경로 IPD를 학습하고 기하 템플릿으로 읽는 비교 기준이며, 27편의 별도 핵심 논문으로 중복 계수하지 않는다.

### S15–21: 좋은 위치 출력과 재사용할 표현은 다른 요구다

다음 단계에 좌표만 전달하는 것과 중간 표현 h를 전달하는 것을 그림으로 대비한다. 위치 추정기 내부의 의미 정보가 모두 사라졌다는 주장은 하지 않는다. 문제는 어떤 정보가 어떤 판독기에 접근 가능한가다. 같은 사건의 위치와 순서를 바꾸는 통제에서 종류·위치·시간이 적절히 유지되거나 바뀌어야 한다.

MC-SimCLR의 crop 일관성, CCSR의 채널 관계 복원, LAM의 물리적 CSM 복원, SFD의 clean 공간 특징은 서로 다른 보존 성질을 유도하는 과제다. 모든 과제의 성능을 보장하지 않는다. 잔향도 DOA에서는 방해가 될 수 있지만 방 특성 판독에서는 목표 정보다. GRAM 프로토콜을 먼저 설명한 뒤 MC-SimCLR의 frozen LP, SFD의 FT, SARL의 요인별 접근성을 읽는다.

### S22–35: 표현을 전달하는 것과 LLM을 적응하는 것을 분리한다

일반화한 설명 골격은 \(H=E(X)\), \(Z=P(H)\), \(\hat y=L(Z,Q)\)다. H는 인코더 특징, P는 projector/connector/resampler 계열의 연결 모듈, Z는 LLM 입력 차원에 맞춘 연속 오디오 토큰이다. Z를 새 단어 ID나 token vocabulary 확장으로 설명하지 않는다. 실제 모델의 여러 분기·결합 방식은 이 단순 골격에 대응시켜 별도로 읽는다.

ELSA·SALM의 검색/정렬은 사건과 위치의 결속을 설명하며 자유형 생성 QA의 성과가 아니다. 시간 평균은 서로 다른 순서·궤적을 같은 요약으로 만들 수 있으므로 Sci-Phi, ST-AudioLM, TWNM에서 실제 전달되는 특징과 토큰 구조를 확인한다. TWNM의 source slots 감독을 곧바로 LLM에 전달되는 source-token 구조로 바꾸어 말하지 않는다.

S31–35는 P의 정렬, LLM의 LoRA 적응, 공간 경로의 별도 학습을 구분한다. LoRA는 LLM 선형층의 저랭크 갱신이며 물리 단서를 직접 추정하는 별도 신호처리기가 아니다. 모든 논문이 같은 단계나 고정 범위를 사용한다고 일반화하지 않는다. Spatial-Omni의 zero-spatial 변형도 고정 checkpoint에서 추론 시 토큰만 지운 실험이라고 단정하지 않는다.

### S36–48: 결과를 변경한 모듈과 관측한 대상에 연결한다

DSpAST의 matched interface는 인코더 설계의 차이를, OWL의 geometry-loss 비교는 표현 학습의 감독 차이를 읽는 근거다. projector/LoRA 하나의 효과와 혼합하지 않는다. connector 설계 비교는 학습 예산·checkpoint 통제의 명시 범위 안에서 읽는다. PhaseCoder의 목표 발화 WER는 음원 선택·결속·전사의 오류를 함께 반영하므로 일반 ASR 보존을 직접 증명하지 않는다.

마지막에는 H의 판독 가능성, Z의 정보 전달, 답변의 오디오 의존을 분리한다. STAR-Bench의 caption 경로, BMLD의 같은 잡음 아래 표적 위상 변경, WearVox의 실제 응답 대상 비교는 서로 다른 실험 대상이다. 임베딩 거리비를 QA 정확도나 인간 검출 역치로 바꾸어 읽지 않는다. S47은 확인한 범위를 종합하고, S48은 같은 장면의 표현·토큰·답변을 연결해 검사하는 연구 질문을 제안한다.

아래 제목은 현재 조립본과 일치한다. 연구 이름을 장의 단위로 삼지 않고, 각 결과가 바로 앞 질문에 답하도록 배열했다.

| S73 | 구간 선택과 thinking의 효과를 분리한다 | Dynamic QA는 mask 조건과 reasoning mode를 분리해 비교한다. |

| S75 | 선택형 점수는 우연 기준부터 확인한다 | STAR의 random guess는 question-only model과 다른 기준이다. |
| S76 | 현장에서는 말의 내용과 응답 대상이 갈린다 | WearVox는 내용 전사만으로 해결되지 않는 기기 응답 대상의 문제를 보여 준다. |
| S77 | 고정 인코더 위에 선형 판독기만 학습한다 | SARL의 linear accessibility는 인코더를 고정하고 라벨로 판독기를 학습한 증거다. |
| S78 | 단서를 제거하며 남은 반응의 원인을 좁힌다 | BMLD 단서 제거는 표현의 반응을 설명하며 accuracy를 재는 실험이 아니다. |

## 7. 문헌 수와 주장 관리

핵심 문헌은 **P01–P27의 27편**이다. 본문·부록을 함께 세며, 일부 논문은 설명 주축 대신 부록의 조건·대안·반례를 담당한다. 한 논문의 여러 장·여러 버전·재구현을 새 논문으로 세지 않는다. GCC/SRP, IPDnet, 좌표계·일반 ML 교육 자료는 설명용 기준으로 별도 취급한다. [현재 학술 구조와 27편 대응표](ACADEMIC_STRUCTURE.md)에 각 문헌의 의미와 본문/부록 위치를 정리했다.

[근거 대장](plans/EVIDENCE_LEDGER.md)과 [P01–P11](plans/EVIDENCE_P01_P11.md), [P12–P23](plans/EVIDENCE_P12_P23.md), [P24–P27](plans/EVIDENCE_P24_P27.md)의 P 식별자는 유지한다. 다만 그 문서들과 이전 BLUEPRINT의 S 번호는 재편 전 위치일 수 있다. 현재 번호는 반드시 CAUSAL_DECK_ORDER의 `number`와 `origin`을 통해 대응시킨다. 원문 버전·표 셀·실험 조건은 원문 및 현재 슬라이드 출처/노트와 함께 확인한다.

색·위계는 전체 라이트 테마를 유지한다. 원문 결과 그림은 원래 범례와 수치를 보존하고, 새 설명 그림은 실제 결과와 구별한다. 도식은 관계를, 수식은 실제 계산을, 그래프는 조건부 성과를 담당한다. 이 문서의 개정은 현재 구조를 문서화한 것이며 새 과학적 실험이나 별도 내보내기 검증을 수행했다는 주장은 아니다.
