# Revision Notes — 좌표 계산에서 LLM 통합으로

## 2026-09-11 · GCC-PHAT와 SRP 설명을 먼저 완성

현재 순서를 **80장: 본문 47장 + 부록 33장**으로 수정했다. 배열 기하 다음의 조기 LLM 로드맵을 제거하고 S07 GCC-PHAT → S08 같은 지연의 위치 궤적 → S09 후보 좌표 점수 → S10 쌍별 합산 → S11 Neural-SRP로 연결한다. S12–S13에서 실제 학습 응답과 실녹음 적응 결과를 확인한 뒤 S14 위치 출력의 한계, S15 인코더·어댑터·LLM/LoRA 구조로 넘어간다. 이후 표현의 관찰 기준과 각 논문의 근거를 읽는다.

GCC-PHAT의 지연 곡선과 공간 좌표 지도를 구분했다. SRP는 후보 좌표의 기하적 시간차로 전체 GCC 곡선을 조회하고 모든 쌍의 점수를 합산한다. 각 쌍의 피크 하나를 먼저 고른다는 설명으로 바꾸지 않는다. Neural-SRP는 쌍별 응답 학습과 합산·argmax 유지로 설명한다. 두 마이크 한 쌍의 지연만으로 3D 좌표를 유일하게 복원했다는 주장은 하지 않는다.

새 도해는 알려진 지연의 합성 신호와 공유 마이크 기하의 수치 계산을 사용하며 원자료와 생성 조건을 함께 보존한다. 파형·GCC 곡선·후보 조회·쌍 응답·합산이 계산상 연결되도록 한다. 논문 실험값과 교육용 계산은 구분한다. S02–S06의 라이트 Manim 다섯 장과 수식 전체 글리프를 포함하는 내보내기 방식은 유지한다.

AGG-RL 세 장은 S49–S51 부록으로 이동했다. 기존 본문에 기초 설명 두 장이 순증하고 AGG 세 장이 빠져 본문은 48→47장, 전체는 78→80장이다. 핵심 문헌 27편, 기존 결과값 99개, 별도로 인용한 TWNM 보고값 3개는 보존 범위다. TWNM의 semantic judge와 exact MCQA, 원문 Overall 집계 불일치에 대한 주의도 유지한다.

이번 산출물 경로는 `output/pptx/spatial-audio-understanding-localization-final.pptx`와 `output/pdf/spatial-audio-understanding-localization.pdf`다. 실제 완료·검수 상태, 개체 수와 해시는 `output/qa/localization/`와 `output/manifest.json`을 따른다. 80장 내보내기·수식·발표 노트 일치·기존 수치 보존 검수를 마쳤다. 새 그림 4장과 변경 6장을 개별 확인하고, 기존 내용은 원본 대응 렌더와 대조했다. 일반 파일명 별칭을 이번 최종본으로 갱신했으며 이전 `-causal` 파일은 이전 개정으로 보존한다.
