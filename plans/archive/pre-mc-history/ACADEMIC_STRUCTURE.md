# 공간 오디오 이해의 학술 구조

갱신: 2026-09-11 · **본문 47장 + 근거 부록 33장** · **핵심 문헌 27편**

이 문서는 현재 [slides.md](slides.md)의 논증과 문헌의 역할을 정리한다. 현재 번호·순서는 [CAUSAL_DECK_ORDER.json](plans/CAUSAL_DECK_ORDER.json), 장별 설명과 전환은 [NARRATIVE_PLAN](NARRATIVE_PLAN.md)을 따른다. 이전 78장 구조는 [직전 보관본](plans/archive/pre-localization/ACADEMIC_STRUCTURE.md), 그보다 오래된 42장 구조는 [이전 보관본](plans/archive/ACADEMIC_STRUCTURE.pre-causal-2026-09-11.md)에 남겼으며 현행 명세가 아니다.

## 1. 좌표 계산을 끝낸 뒤 통합 구조로 넘어간다

발표는 **배열 기하 → GCC-PHAT → SRP → Neural-SRP → 인코더·어댑터·LLM/LoRA** 순서로 설명한다. GCC-PHAT이 만드는 지연 곡선과 후보 좌표의 공간 지도를 먼저 구별해야 학습으로 바뀌는 연산을 이해할 수 있다. 그다음 좌표만으로 답할 수 없는 사건·시간·관계 질문을 통해 재사용할 표현과 LLM 연결의 필요성을 설명한다.

| 단계 | 연산·대상 | 질문 | 본문 |
| --- | --- | --- | --- |
| 관측과 기하 | 두 채널 신호, 경로차, 마이크 배열 | 위치가 관측의 어떤 차이를 만드는가? | S02–S06 |
| GCC-PHAT와 SRP | 지연 곡선 → 후보의 기대 지연 조회 → 쌍 합산·argmax | 관측을 어떻게 좌표로 바꾸는가? | S07–S10 |
| 학습한 공간 응답 | Neural-SRP의 쌍별 위치 응답 | 무엇을 학습하고 무엇을 유지하는가? | S11–S13 |
| LLM 통합과 표현 | H=E(X), Z=P(H), LLM(Z,Q)와 LoRA | 좌표 외에 어떤 정보를 남기고 연결하는가? | S14–S21 |
| 토큰 전달 | 의미·공간·시간의 분기·압축·결속 | 관계를 어떤 구조로 전달하는가? | S22–S29 |
| 학습과 근거 | P 정렬, LLM 적응, 모듈·목표 비교 | 결과는 어느 변경의 근거인가? | S30–S40 |
| 실제 정보 사용 | H 판독, Z 전달, 답변 의존의 별도 검사 | 답이 실제 소리에 근거하는가? | S41–S47 |

이는 계산과 정보 흐름을 설명하는 순서다. 논문 간 역사적 계승이나 서로 다른 시스템 점수의 인과적 개선 곡선을 뜻하지 않는다. AGG-RL의 배열·후보 일반화는 기초 계산 뒤에 선택할 부록 S49–S51로 옮겼다.

## 2. 계산을 학습으로 바꿀 때의 정확한 구분

GCC-PHAT은 지연축의 점수 곡선을 만든다. SRP는 후보 좌표의 기하로 기대 지연을 구하고, 그 지연의 곡선 값을 읽는다. 각 쌍의 최대 지연 하나만 먼저 정하는 설명으로 축약하지 않는다. Neural-SRP는 **쌍별 공간 응답**을 학습하면서 쌍 합산과 argmax를 유지한다. 두 마이크의 같은 지연을 만드는 위치가 여럿이므로 한 쌍의 타깃은 점이 아니라 능선이다. 한 쌍 TDoA만으로 3D 좌표가 유일하게 결정되지는 않는다.

도입은 \(\tau=t_2-t_1\), Neural-SRP 원문 대응은 \(\tau_{ij}=t_i-t_j\)다. 따라서 \(\tau_{\mathrm{intro}}=\tau_{21}=-\tau_{12}\)로 읽고 상관의 채널 순서도 맞춘다. S02의 α/β/r는 최종 목표의 좌표 정의이며 Neural-SRP의 알려진 높이 2D 실험을 3D 복원으로 바꾸지 않는다.

| 방법 | 학습되는 대상 | 유지되거나 별도로 주어지는 것 | 이 발표에서의 구별 |
| --- | --- | --- | --- |
| SRP-PHAT | 학습 없음 | 알려진 마이크 기하, 후보 지연 조회·쌍 합산 | 기하/후보 격자를 바꿀 수 있는 분석적 기준 |
| IPDnet | 직접 경로 IPD 벡터 | 기하 IPD 템플릿 내적; 기준쌍 집계 | 공간 지도 직접 학습과 다른 학습 위치를 설명하는 보조 기준 |
| Neural-SRP 2024 | 위상·쌍 좌표·방 크기 → 25×25 위치 응답 | 모든 쌍의 응답 합과 최대점 선택 | 후보 좌표는 학습 타깃 구성용이며 추론 입력이 아님 |
| AGG-RL 2026 | 관측·기하 표현과 후보 방향 표현의 정합 | 주어진 배열 좌표와 질의 방향 목록 | 배열 변경과 후보 목록 변경을 서로 다른 축으로 검사 |

AGG-RL의 비교표에 등장하는 Neural-SRP는 time-domain GCC-PHAT·Fibonacci DOA 격자·복수 응답으로 수정한 재구현이다. 원문 2024의 2D 위치 모델과 같은 checkpoint의 단계적 개선이 아니다. S13의 Recorded4 위치 오차와 S51의 Dynamic-U 각도 오차는 합쳐 순위를 만들지 않는다. S51은 미노출 채널 수의 평가이며 S49의 격자 재질의 기능 전체를 그 결과 하나로 입증하지 않는다. 상세 대조는 [CAUSAL_SIGNAL_BRIDGE](plans/CAUSAL_SIGNAL_BRIDGE.md)에 기록했다.

P01–P27은 문헌의 고정 식별자다. **27편은 본문과 부록을 함께 센 범위**이며, 모든 논문에 독립된 본문 장을 배정하지 않는다. 같은 논문의 원형·재구현·여러 버전·여러 결과 장을 중복 계수하지 않는다. GCC/SRP, IPDnet, 좌표계와 일반 학습 프로토콜의 교육 출처는 별도 보조 자료다.

## 4. 학습 목표와 검증 프로토콜을 혼합하지 않는다

현재 **S18 GRAM 프로토콜 → S19 MC-SimCLR 고정 판독 → S20 SFD 미세조정 → S21 SARL 속성별 판독** 순서는 평가를 읽는 기준을 먼저 세운다. 한 연구의 사전학습 목표가 좋다는 설명과 실제로 어느 정보를 어느 방식으로 읽었다는 증거를 구별한다.

| 실험 | 고정/갱신 범위 | 확인할 수 있는 것 | 그것만으로 확인할 수 없는 것 |
| --- | --- | --- | --- |
| 고정 인코더 LP | E 고정, 라벨로 작은 판독기 학습 | 그 판독기의 용량·데이터 조건에서 접근 가능한 정보 | 모든 비선형 정보의 존재/부재, LLM의 사용 |
| 전체 미세조정 | E와 downstream head 갱신 | 사전학습이 적응에 유용한 초기화인가 | 학습 전 H에서 이미 쉽게 읽혔는가 |
| P 정렬 | 방법별로 E/LLM을 고정하고 P 등을 학습 | 인코더 특징과 LLM 입력의 연결이 학습되는가 | 모든 시간·음원 구조가 자동 보존되는가 |
| LLM LoRA/언어 적응 | 원문이 명시한 선형층·LoRA·부가 모듈 갱신 | 주어진 토큰을 처리하는 학습 방식의 결과 | E가 특정 물리 단서를 정확히 추정했는가 |
| token/경로 변형 비교 | 학습·추론 중 무엇을 바꿨는지 명시 | 해당 조건에서 토큰/경로의 기여 | 변경하지 않은 요소까지의 독립 효과 |
| 통제 자극의 표현 반응 | 입력의 특정 조건을 바꾸고 E의 반응 측정 | 그 자극에 표현이 어떻게 달라지는가 | 정답 판독 성능, 인간 지각과 동일한 기전 |
| 전체 QA/현장 시스템 | 입력·학습·질문·채점 조건의 묶음 | 그 시스템의 해당 과제 성과 | 내부 모듈 하나의 인과 기여 |

LoRA는 예를 들어 \(W_{\mathrm{eff}}=W_0+(\alpha/r)BA\)로 선형층을 저랭크 적응하는 방식이다. P가 연속 오디오 토큰을 만들고, LoRA는 LLM의 입력 처리 방식을 조정한다. P 학습과 LoRA가 반드시 서로 배타적이거나 항상 같은 순서인 것은 아니며, 각 논문에서 어떤 가중치를 고정하고 갱신했는지 확인한다.

## 5. 본문과 부록의 선택 원칙

본문 S01–S47은 관측에서 좌표를 구하는 계산을 완성한 뒤, 어떤 정보를 남겨 LLM에 전달할지 설명한다. 원문 수치는 바로 앞 질문에 답하는 비교를 사용한다. 같은 논문이 E/P/LLM의 여러 질문에 관여하면 서로 다른 위치에서 다시 읽는다.

부록 S48–S80은 33장이다. S48은 진입 장, S49–S51은 AGG-RL의 배열·후보 확장, 이후는 관측·인코더·결속·전달·시간·답변 근거를 확인하는 선택 자료다. 이 배치는 각 연구의 중요도나 성능 순위를 뜻하지 않는다.

S16·S25·S41·S47의 공통 도해는 보존 조건, 압축 반례, 검증 질문을 설명한다. S46은 기존 근거의 종합이며 S47은 미실행 후속 연구 제안이다. 설명용 계산을 논문 성능값이나 완료된 후속 실험으로 읽지 않는다.

## 6. 정확성·표기·추적 기준

- 관측 입력, 추론 시 메타데이터, 학습 전용 감독을 분리한다. FOA는 임의의 마이크 네 개와 같지 않으며, OWL의 depth/RIR 지도와 PhaseCoder의 추론 좌표는 역할이 다르다.
- 새 배열, 새 후보 격자, 새 방, 새 음원 정체성, 새 입력 형식은 별도 일반화 축이다. 지도 사전학습과 무라벨/자기지도 사전학습도 구별한다.
- 의미 분류, DOA, SELD, 검색, 목표 조건부 위치 추정, 생성 QA, 전사는 서로 다른 출력이다. 어느 한 성과가 나머지 출력을 보장하지 않는다.
- 정량 비교에는 입력, 갱신한 모듈, 학습 데이터, 시험 분할, 지표를 붙인다. 동일 논문 안의 비교라도 바뀐 조건이 여러 개이면 단일 요소의 효과로 단정하지 않는다.
- source-level semantic/localization/room 판독을 구분한다. S21은 Fig.2의 정규화 판독을 읽는다. 표현 민감도는 별도 정의·그림이며 낮은 선형 접근성도 모든 정보의 부재를 뜻하지 않는다.
- 같은 종류의 두 음원을 구분하는 identity, 속성의 음원별 결속, 시간 순서 판독은 다르다. 평균 pooling이나 단순 attribute 목록만으로 모두 해결되었다고 말하지 않는다.
- 원문 그림과 재구성 데이터는 provenance를 유지한다. 설명용 파형·능선·토큰·연결 도해는 실측이나 실제 모델 출력과 명확히 구별한다. 모든 자체 도해와 Manim은 동일 라이트 테마를 유지한다.

[근거 대장](plans/EVIDENCE_LEDGER.md)은 P 번호와 현재 S 번호를 대응한다. 개별 과거 근거 카드의 S 번호는 원본 O 번호일 수 있다. 현재 위치는 [CAUSAL_DECK_ORDER](plans/CAUSAL_DECK_ORDER.json)의 `number`와 `origin`, 그리고 조립된 [slides.md](slides.md)의 본문/노트를 대조한다. 이전 BLUEPRINT와 보관 문서의 순서를 현재 구조로 오인하지 않는다. 논문 원문·현재 출처·근거 카드의 비교 조건을 우선하고, 이 구조 문서의 짧은 설명은 그 조건을 대체하지 않는다.
