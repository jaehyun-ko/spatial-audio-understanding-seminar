# 공간 소리를 듣고 판단하는 모델: 설명 순서

갱신: 2026-09-11 · **본문 S01–S47 + 근거 부록 S48–S80 = 80장** · 핵심 문헌 27편

현재 순서·제목·역할의 기준은 [CAUSAL_DECK_ORDER.json](plans/CAUSAL_DECK_ORDER.json)이다. 이전 78장 구성은 [보관본](plans/archive/pre-localization/NARRATIVE_PLAN.md)에 남겼다. 내보내기 상태는 [README](README.md)와 산출물 검수 기록을 따른다.

## 1. 배열 기하 다음에는 좌표를 찾는 계산을 완성한다

핵심 순서는 **관측과 배열 기하 → GCC-PHAT → 시간차의 위치 모호성 → SRP → Neural-SRP → 인코더·어댑터·LLM/LoRA**다. 좌표 계산을 설명하기 전에 LLM 로드맵이나 문헌 목록으로 넘어가지 않는다.

S02는 x축의 두 마이크와 중점 원점 O를 기준으로 방위각 α, 고도각 β, 거리 r를 정의한다. α는 +x에서 +y 방향, β는 xy 평면에서 +z 방향이다. S03–S06은 같은 장면에서 도달 신호·경로차·잔향과 혼합·마이크 간격을 차례로 보여준다. 이 목표 정의는 한 쌍 TDoA로 3D 좌표를 유일하게 찾았다는 주장이 아니다.

S07은 두 신호의 교차스펙트럼을 PHAT로 정규화하고 역변환해 **지연축 점수 곡선**을 얻는다. 최대점은 시간차의 예시 추정값이다. S08은 같은 시간차의 위치가 여러 개라는 것을 기하로 보여준다. S09는 각 후보 좌표의 거리차/c를 구한 뒤 곡선의 해당 지연에서 점수를 읽는다. S10은 세 마이크의 세 쌍 점수를 합산하고 최대 후보를 선택한다. **SRP는 각 쌍의 피크 하나만 먼저 선택해 교차시키는 설명이 아니다.** 전체 곡선을 후보 기하로 조회한다.

S07–S10의 신호·기하·GCC·공간 응답은 하나의 공유 합성 장면에서 계산한 교육용 예다. 논문의 성능 측정이나 실제 신경망의 출력이 아니다. S07–S10은 같은 기하의 후보와 마이크를 유지하며 쌍 응답에서 합산으로 이동한다. 평면 예에서 피크를 좁히는 것과 제약 없는 3D 유일성을 구별한다.

도입은 τ=t₂−t₁, GCC/SRP 표기는 τᵢⱼ=tᵢ−tⱼ를 사용한다. 따라서 도입 τ=τ₂₁이고 τ₁₂와 부호가 반대다. 교차스펙트럼의 채널 순서·거리차·지도 조회를 같은 정의로 맞춘다.

## 2. 고정 연산과 학습할 연산을 같은 그림에서 비교한다

S11에서 SRP의 쌍 응답 생성 자리를 Neural-SRP로 바꾼다. 원문 2024 모델은 쌍별 STFT 위상·마이크 좌표·방 크기에서 25×25 위치 응답을 학습하며, 모든 쌍의 합산과 argmax를 유지한다. 같은 TDoA를 만드는 능선이 학습 타깃이며 한 점 Gaussian이나 확률 지도라고 말하지 않는다. 후보 좌표는 학습 타깃 구성에 쓰며 추론 입력이 아니다. 원문 실험은 높이를 고정한 2D 위치 추정이다.

S12의 실제 응답 그림과 S13의 Recorded4 추가 학습 결과는 각각 정성·정량 근거다. AGG-RL의 배열/후보 격자 변경은 부록 S49–S51에 둔다. 그 논문의 Neural-SRP는 GCC-PHAT·Fibonacci DOA 격자로 수정한 재구현이므로 원형의 실녹음 위치 오차와 하나의 개선 곡선으로 잇지 않는다. SRP도 알려진 새 기하와 후보를 계산에 적용할 수 있다.

## 3. 좌표를 찾은 다음 LLM에 필요한 표현을 설명한다

S14에서 “어디인가”의 좌표만으로 “무슨 소리가 언제 났는가”에 답할 수 없는 이유를 보여준다. 이는 위치 추정기 내부가 의미 정보를 모두 지웠다는 주장이 아니다. 다음 소비자에게 무엇을 전달할지의 문제다.

S15에서 **H=E(X) → Z=P(H) → LLM(Z,Q)**와 LLM 내부 LoRA를 먼저 설명한다. E는 사건·공간·시간의 표현을 만들고, P는 연속 오디오 토큰을 LLM 입력 차원과 길이에 맞춘다. LoRA는 전달된 입력을 처리하는 LLM 선형층을 적응한다. 입력 시퀀스에 연속 임베딩이 추가되는 것과 어휘 수·임베딩 폭의 증가는 별개다. LoRA는 대표적인 학습 선택이며 모든 모델의 필수 요소로 일반화하지 않는다.

이 공통 구조를 보인 뒤 S16–S21에서 필요한 성질과 판독 근거를 읽는다. 위치만·종류만·순서만 바꿀 때 유지할 정보와 변할 정보를 구분한다. 학습 목표와 검증은 다르므로 GRAM의 프로토콜 → MC-SimCLR의 고정 판독 → SFD의 전체 미세조정 → SARL의 요인별 판독을 연결한다.

S22–S29는 의미·위치 결속과 시간 구조를 전달하는 선택, S30–S34는 P 정렬과 LLM 적응, S35–S40은 변경한 모듈과 결과의 관계를 다룬다. 논문은 앞에서 정한 E/P/LLM의 질문에 답하는 근거로 배치한다. 검색과 생성 QA, source-slot 감독과 dense 토큰 입력, 전체 모델 변형과 고정 checkpoint 개입을 구별한다.

S41–S47은 표현 접근성·토큰 전달·답변 사용을 서로 다른 검사로 읽는다. SARL probe는 LLM 사용의 증거가 아니고, BMLD 임베딩 거리는 인간 역치나 QA 정확도가 아니다. STAR의 random guess와 BAT의 질문만 기준선도 구분한다. S47은 같은 장면의 H·Z·답을 함께 검사하는 **미실행 제안**으로 끝난다.

## 4. 현재 장별 역할

다음 표는 순서 명세의 현재 번호와 역할을 기록한다. 여러 논문의 성능을 한 모델의 단계별 통과로 해석하지 않는다. 47장 본문 뒤의 33장 부록은 질문에 따라 선택하며, 이전 개정의 발표 시간 예산을 현재 리허설 결과로 재사용하지 않는다.


### 01 · 신호에서 좌표를 찾는 과정

| 장 | 현재 제목 | 설명 역할 |
| --- | --- | --- |
| S01 | 공간 소리를 듣고 판단하는 모델 | 발표의 중심 질문은 공간 단서를 LLM의 답변까지 전달하고 사용하게 만드는 조건이다. |
| S02 | 공간 오디오 이해의 목표 | 출력 목표인 종류·방위각·고도각·거리를 좌표로 정의한다. |
| S03 | 두 채널 관측 신호 | 같은 음원의 전파가 채널별 관측 차이가 되는 과정을 본다. |
| S04 | 경로 차이와 시간차 | 기하가 도달 시간차를 결정하므로 위치 계산의 물리적 근거가 생긴다. |
| S05 | 잔향과 음원 혼합 | 잔향과 다른 음원이 겹치면 단순한 직접음 관계를 읽기 어려워진다. |
| S06 | 마이크 배열 기하 | 배열이 달라지면 같은 위치의 관측도 달라진다. 이 기하는 이후 학습 모델에서도 사라지지 않는다. |
| S07 | GCC-PHAT: 두 신호에서 시간차를 찾는다 | 두 채널의 위상 관계를 지연축 점수 곡선으로 바꾸고, 곡선의 최대점에서 시간차를 읽는다. |
| S08 | 지연 하나에 대응하는 좌표는 여러 개다 | 측정한 시간차는 같은 거리차를 갖는 후보 곡선을 정한다. 한 쌍으로는 좌표 하나를 정할 수 없다. |
| S09 | 후보 좌표가 예측한 지연에서 상관값을 읽는다 | 후보 좌표에서 두 마이크까지 거리를 계산하고, 예상 지연의 GCC-PHAT 값을 읽는다. |
| S10 | 쌍별 응답을 합하고 가장 높은 좌표를 고른다 | 마이크를 하나 더 놓아 세 쌍의 후보 점수를 합산하고 전체 공간 응답이 최대인 좌표를 선택한다. |
| S11 | Neural-SRP: 쌍별 공간 응답을 학습한다 | Neural-SRP는 직접 좌표 회귀가 아니라 쌍별 위치 응답을 학습하고 합산 구조를 유지한다. |
| S12 | 학습한 쌍별 응답을 합치면 위치 피크가 달라진다 | 그림은 학습 응답이 어떤 형태의 변화를 만들 수 있는지 보여 주는 정성 예시다. |
| S13 | 학습한 응답의 효과는 실녹음 적응 조건에서 확인한다 | NeuralSRP+의 적응량과 시험 조건을 붙여, 학습 응답의 결과를 확인한다. |

### 03 · 그 정보를 어떤 토큰으로 전달할 것인가

| S25 | 시간 평균은 서로 다른 이동을 같게 만들 수 있다 | 차원을 맞추는 것만으로 충분하지 않다. 압축과 pooling이 source·time 관계를 잃게 할 수 있으므로 전달 구조를 정한다. |
| S26 | 기존 의미 경로에 공간 토큰 경로를 더한다 | Sci-Phi는 고정된 의미 인코더·projector·audio LoRA를 유지하며 공간 인코더·projector·spatial LoRA를 적응하는 분기 설계다. |
| S27 | 시간별 궤적을 남긴 토큰을 LLM에 전달한다 | ST-AudioLM은 의미 토큰과 동적 궤적 토큰을 고정 encoder에서 꺼내 connector·LoRA로 연결한다. |
| S28 | 같은 토큰 수에서도 시간 구조를 배운 표현은 다르다 | 같은 FOA·OLMo2·41-token 인터페이스 비교에서 encoder의 시간 구조 차이를 본다. connector 하나의 효과로 귀속하지 않는다. |
| S29 | 음원 단위 감독과 LLM에 보내는 특징을 구별한다 | TWNM의 source slots는 학습 감독이고 실제 hybrid projector에는 dense encoder map이 전달된다. |

### 04 · 어댑터 정렬과 LLM 적응의 역할

| 장 | 현재 제목 | 설명 역할 |
| --- | --- | --- |
| S30 | 연결 정렬과 언어 적응은 다른 학습 단계다 | 인코더가 만든 특징의 의미와 LLM의 입력 해석을 연결하려면 어떤 모듈을 언제 고정하고 학습할지 정해야 한다. |
| S31 | 표현 정렬·언어 적응·공간 경로 학습을 단계로 나눈다 | Spatial-Omni는 projector 정렬, LoRA, 공간 경로 적응을 나눠 학습하는 구체적인 사례다. |
| S32 | 공간 토큰을 쓰는 모델과 zero-spatial 변형을 비교한다 | Spatial-Omni의 zero-spatial 변형과 full 모델을 비교한다. 고정 checkpoint에서의 추론 시 제거 실험이라고 단정하지 않는다. |
| S33 | LoRA는 LLM의 입력 처리 방식을 조정한다 | LoRA는 추가 연속 audio token을 읽는 LLM의 선형층을 저랭크로 적응하는 방식이다. token vocabulary 확장 자체가 아니다. |
| S34 | 언어 학습 목표를 바꾸면 지각과 복합 질의가 함께 바뀐다 | TWNM SFT→SAPO는 복합 질의가 좋아져도 기본 지각·관계 연결이 낮아지는 trade-off를 드러낸다. |

### 05 · 바꾼 모듈과 성능의 관계를 읽기

| 장 | 현재 제목 | 설명 역할 |
| --- | --- | --- |

## 5. 수치와 문헌 추적

핵심 문헌 P01–P27은 고정 ID다. 본문과 부록을 함께 세며 GCC/SRP·IPDnet·좌표계 교육 자료를 중복 계수하지 않는다. 원본 O01–O78과 현재 S01–S80의 대응은 [근거 인덱스](plans/EVIDENCE_LEDGER.md)에 있다. 원래 파일명 `result-NN`은 현재 페이지가 아니라 원본 O 번호다.

기존 보고값 99개와 TWNM adapter 보고값 3개는 각각 원자료를 유지한다. 새 합성 GCC/SRP 계산은 이 보고값 집합에 포함하지 않는다. 다른 지표를 한 점수로 합치지 않으며 제안 실험을 이미 수행했다고 표현하지 않는다. 상세 원문 조건은 발표 노트와 근거 카드가 짧은 본문 설명을 보완한다.
