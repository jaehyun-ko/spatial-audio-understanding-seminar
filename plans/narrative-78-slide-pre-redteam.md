# 공간 소리를 듣고 판단하는 모델: 최신 문헌을 포함한 확장 흐름

개정: 2026-09-09  
문헌 확인 기준일: 2026-09-09

이 문서는 다음 슬라이드 개정을 위한 설계안이다. 사용자의 요청에 따라 이전 32장 제한을 해제했다. 본문 78장, 설명 약 100–110분을 작업 기준으로 잡는다. 질의응답과 선택적 확장은 별도다. 장수는 내용 배치의 기준이며 제작 전 고정된 제한은 아니다.

현재 slides.md와 PDF는 기존 42장 그대로다. 새 그림 취득이나 슬라이드 렌더링은 아직 하지 않았다. [이전 32장 설계안](plans/narrative-32-slide-draft.md)은 비교용으로 보존한다. ACADEMIC_STRUCTURE.md는 실제 현재 덱의 설명으로 유지한다.

## 1. 발표의 질문과 범위

중심 질문: **모델은 소리를 듣고, 무엇이 어디에서 어떻게 일어나는지 판단할 수 있는가?**

공간 소리의 지각, 표현 학습, 언어 정렬, 목표 선택, 장면 기술, 공간 관계와 움직임 판단을 다룬다. 최신 문헌을 끝에 붙이는 대신 각 논문이 답하는 질문에 배치한다. 논문 발표 순서는 설명 순서다. 시간순 발전 단계나 앞선 방법의 직접적인 대체 관계로 그리지 않는다.

- 주 입력은 오디오다. 질문 텍스트나 목표 소리 예시는 허용한다.
- 생성, 재생, 렌더링, 장치 설계, 로봇 행동은 독립 주제로 확장하지 않는다.
- 목표 선택의 출력이 DOA·활성 음원 수인 SelectTSL은 본문에 넣는다. 분리 파형 생성 자체를 주제로 삼지는 않는다.
- 시각 정보를 추론 때 함께 쓰는 JAEGER와 ST-Omni-R1은 별도의 선택적 확장으로 구분한다.
- 언어 모델 외에도 DOA 판독, SELD, 오디오–텍스트 검색을 청각 판단의 방식으로 설명한다.
- 이번 조사는 이 범위의 선택적 최근 문헌 리뷰다. 모든 논문을 빠짐없이 망라했다고 주장하지 않는다.
- 공개일, 수정일, 학회 게재일을 구별한다. 예를 들어 Spatial-Omni는 2026-06-09 첫 arXiv 공개, 2026-09-07 v2 수정이다.

청중은 기본적인 머신러닝을 알지만 공간 음향에는 익숙하지 않은 대학원 세미나 청중으로 가정한다.

## 2. 설명의 중심 장면과 발표 방식

왼쪽에는 말소리, 오른쪽에는 알람이 있다. 처음 질문은 **“알람은 어느 쪽에서 울리는가?”**다.

도입에서 단일 알람으로 경로차를 설명한 뒤, 두 음원 장면으로 돌아온다. 이후 위치 교환, 알람을 찾으라는 질의, 다른 소리와의 거리 비교, 사건 순서 교환, 알람 발생 장치의 이동을 각각 다른 조건으로 추가한다. 한 번에 모든 복잡성을 추가하지 않는다.

다중 음원, 공간 관계, 시간 변화는 서로 다른 과제 축이다. 한 음원의 움직임도 시간 판단을 요구하고, 정지한 두 음원도 대상과 위치의 올바른 결합을 요구한다. 이들을 단순한 난도 사다리로 만들지 않는다.

이 장면은 설명용 사고실험이다. 실제 모델의 실패나 성공으로 표시하지 않는다. 원문 예제를 재구성할 때에는 원문 기반 재구성과 발표자의 설명용 장면을 구분한다.

각 중심 논문에서 먼저 관측이나 과제의 어려움을 보여준다. 그다음 필요한 설계 선택과 실제 평가 결과를 설명한다. 대체로 2–3장을 사용하되, 두 장 구성에서는 첫 장에 문제와 핵심 방법, 둘째 장에 결과와 조건을 담는다. 구조도 한 장으로 문제·방법·결과를 모두 대신하지 않는다.

ELSA와 SALM은 검색·분류를 위한 정렬 표현을 설명하는 중심 사례다. 생성형 LLM의 자유형 QA와 구별한다. SALM의 ‘editing’은 여기서는 임베딩 조작으로만 설명하며 파형 생성 성과로 쓰지 않는다.

SelectTSL은 두 채널 혼합음과 텍스트 및/또는 예시 오디오로 목표를 지정한다. full model의 text+audio 조건을 text-only 모델처럼 표시하지 않는다. MAE는 true positive의 각도 오차이고, MOTA*에는 identity-switch 벌점이 없다는 조건을 유지한다. 실측 SRIR 합성과 현장 혼합음 녹음을 구별한다.

전환: 목표를 고르거나 문장과 맞추는 것을 넘어, 질문별 답변을 생성하려면 공간 표현을 어떻게 연결할까?

## 9. 실제 제작에 넘길 조건

1. 앞의 8장에는 논문 목록이나 아키텍처 지식이 필요하지 않아야 한다.
2. 각 중심 논문은 고유 문제의식과 최소 하나의 결과·평가 조건을 본문에 갖는다. 상세 구조나 전체 표만 부록으로 보낸다.
3. 문제의식 그림은 번호로 고르지 않는다. AGG-RL Fig. 1, SelectTSL Fig. 1, TWNM Fig. 1, STAR-Bench Fig. 1은 문제 설명에 적합하다. ST-AudioLM·Sci-Phi·CoSTALA의 Fig. 1은 구조도다.
4. 적절한 원문 문제 그림이 없으면 문제 예제와 서술을 근거로 별도 장면을 기획한다. 출처와 재구성 여부를 표시한다.
5. 그림 확보, 크롭, 출판본 대조, 최종 표시할 결과 행·열 선정은 아직 남아 있다. 계획서가 이미지 자산의 취득이나 시각 검증 완료를 뜻하지 않는다.
6. 서로 다른 입력·학습 데이터·판독 방식의 모델 수치를 통합 순위표로 만들지 않는다. 프리프린트 결과는 원고의 보고로 표시한다.
7. 새 배열, 새 panning amplitude, 새 방, 새 음원, 새 질문 조합은 서로 다른 일반화 조건이다.
8. 실제 녹음, 실측 RIR 합성, 완전 합성을 구별한다. 다중 음원 tracking과 두 사건의 순서 검색도 구분한다.
9. 최신 원고의 버전 변화가 입력·방법·평가를 바꾸면 해당 슬라이드 전체를 같은 버전으로 맞춘다.
10. 긴 발표의 종합은 연구별 질문을 회수하는 데 사용한다. 이름만 다시 나열하는 요약 페이지는 추가하지 않는다.
11. 현 덱의 수식·추가 표·용어·참고문헌·연구 제안은 보존한다. 실제 개정 때 부록을 새 본문에 맞춰 재색인한다.
12. 현재 검증 스크립트의 장수 제한과 내보내기는 실제 덱 개정 때 조정·검증한다. 설계 단계에서는 slides.md, style.css, PDF를 변경하지 않는다.
