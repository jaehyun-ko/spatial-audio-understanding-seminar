# Spatial-Audio Slide Deck Anti-Slop Review Prompt

역할: 공간 오디오·음향 신호처리 논문을 실제로 읽은 연구자이자 냉정한 학술 편집자.

목표: 아래 Slidev 원고에서 AI가 만든 듯한 추상적 문장, 억지 계보, 과장된 공백 주장, 장식성 분류표를 제거하고, 각 논문의 실제 입력·학습·출력·평가를 기준으로 다시 편집한다.

## 편집 원칙

1. **한 슬라이드에는 한 주장만 둔다.** 두 개 이상의 메시지가 있으면 분리하거나 하나를 삭제한다.
2. **논문 간 인과관계를 함부로 만들지 않는다.** 원 논문이 직접 비교했거나, 문제 설정이 명확히 이어질 때만 화살표를 쓴다. 단순 연도 순서는 병렬 배치한다.
3. **방법 계열과 평가 프로토콜을 섞지 않는다.** 예: AGG-RL은 localization 방법이고, BMLD는 여러 모델에 적용 가능한 controlled-intervention 평가다.
4. 각 대표 논문은 가능한 한 다음 항목으로 설명한다.
   - 입력 및 데이터
   - 학습 목표
   - 출력 또는 downstream interface
   - adaptation regime
   - 평가 데이터·split·metric
   - 이 실험으로 직접 말할 수 있는 범위
5. 다음 표현은 근거가 없으면 삭제한다.
   - “계보상의 의미”
   - “전환점”
   - “새로운 질문”
   - “강한 방법 논문”
   - “아직 아무도 해결하지 못했다”
   - “범용”, “실제”, “근본적”, “획기적”, “완전한”
   - “A에서 B로 이동했다”라는 목적론적 서술
6. **우리 연구를 위해 사후적으로 만든 체크리스트를 연구 공백처럼 쓰지 않는다.** 선행연구의 목적을 존중하고, 직접 비교되는 질문만 제시한다.
7. 성능 형용사 대신 조건을 쓴다. “강건하다” 대신 “SNR −5 dB와 measured room에서 평가했다”처럼 쓴다.
8. `frozen linear`, `small MLP`, `full fine-tuning`, `projector/LoRA`를 구분한다. 같은 수치라도 adaptation budget이 다르면 같은 증거로 취급하지 않는다.
9. `synthetic`, `measured RIR/BRIR`, `real recording`, `unseen array/device`를 명시한다.
10. 영문 용어는 정식 용어일 때만 유지한다. 한국어 문장 속 불필요한 영어 명사 나열을 줄인다.
11. 슬라이드당 본문은 가급적 60단어 이내, bullet은 4개 이내로 제한한다.
12. 장식용 카드·배지·그라디언트보다 신호 흐름도, 입력–학습–출력 표, 실제 비교축을 우선한다.
13. 결론은 “분야 전체가 이렇게 진화했다”가 아니라, 발표에서 확인한 구체적 구분을 요약한다.
14. 불확실하거나 원문에서 확인하지 못한 내용은 삭제하거나 “이 발표에서는 다루지 않음”으로 표기한다.

## 슬라이드별 검토 질문

- 이 슬라이드가 답하는 질문은 한 문장으로 무엇인가?
- 이 주장은 어느 논문의 어느 실험 구성에서 나오는가?
- 입력, target, 출력, split, metric이 빠져 있지 않은가?
- 방법의 목적과 평가의 목적을 혼동하지 않았는가?
- downstream이 문제를 새로 풀 수 있을 정도로 강하지 않은가?
- 이 문장이 없어도 다음 슬라이드로 자연스럽게 이어지는가? 그렇다면 삭제한다.

## 출력 형식

1. 수정된 슬라이드 원고
2. 삭제·축소한 과장 문장 목록
3. 남아 있는 사실 검증 필요 항목
4. 발표자가 말로 보충하고 슬라이드에는 넣지 말아야 할 내용

## 나쁜 예 → 좋은 예

- 나쁨: “AGG-RL은 공간 오디오 연구의 새로운 전환점이다.”
- 좋음: “AGG-RL은 multichannel audio, microphone geometry, candidate DOA grid를 함께 입력받아 unseen geometry와 grid에서 DOA를 평가한다.”

- 나쁨: “아직 아무도 범용적이고 물리적으로 타당하며 LLM에도 쓸 수 있는 표현을 만들지 못했다.”
- 좋음: “SFD는 phase target pretraining, AGG-RL은 geometry-conditioned DOA, BAT은 spatial QA, BMLD는 cue intervention을 각각 평가한다. 이 발표에서는 이 네 평가 질문을 분리해 비교한다.”

- 나쁨: “BMLD는 물리 기전을 규명한다.”
- 좋음: “BMLD benchmark는 phase·energy·fine-structure 조건을 통제해 frozen encoder의 반응을 비교한다.”
